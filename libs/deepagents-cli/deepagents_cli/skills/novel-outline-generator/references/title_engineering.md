# 标题工程指南

## 概览

标题是读者的第一印象，决定了是否点开。好标题不是文艺的修辞，而是**精准传递核心困境**的工程。

---

## 冒号标题公式

### 基本结构

```
「世界观标识：核心困境/荒诞设定」
```

- **冒号前**：快速告诉读者这是什么世界（海贼王/火影/红楼/三国）
- **冒号后**：用最短的话传递"为什么要看"——核心困境、荒诞反差、或致命设定

### 正反案例对比

| 维度 | ❌ 失败标题 | ✅ 成功标题 | 为什么 |
|------|-----------|-----------|--------|
| 信息量 | 海贼王之最强 | 海贼王：我吃了手术果实，但罗要杀我 | 后者暗示了核心冲突 |
| 困境感 | 火影之天才忍者 | 火影：转生眼暴露，全族要灭我口 | 后者有不可逃避的困境 |
| 反差感 | 红楼梦同人 | 红楼：我是贾宝玉，但我想考科举 | 后者有荒诞的身份反差 |
| 悬念感 | 三国之霸主 | 三国：我是董卓，还有三天可活 | 后者有倒计时紧迫感 |
| 具体感 | 斗破之强者归来 | 斗破：药老要杀我夺舍，倒计时七天 | 后者有具体的威胁和期限 |

## 五大标题模式

### 模式1：困境逆袭型

**公式**：「世界观：我陷入XX困境」

**核心**：标题直接展示不可逃避的困境，暗示主角将如何逆袭。

**示例**：
- 海贼王：我吃了手术果实，但罗要杀我
- 火影：转生得到写轮眼，宇智波要灭我口
- 斗破：药老寄生在我体内，七天后夺舍

**要素**：
- 明确的困境（被追杀/被倒计时/被陷害）
- 困境来源于核心设定（不是随机意外）
- 暗示了引擎（追杀/倒计时/暴露风险）

### 模式2：荒诞身份型

**公式**：「世界观：我是XX，但我要YY」

**核心**：身份和目标的荒诞反差，制造阅读欲望。

**示例**：
- 红楼：我是林黛玉，但我想当女帝
- 水浒：我是武大郎，但我要当首富
- 海贼王：我是天龙人，但我想当海贼

**要素**：
- 身份本身有明确特征（读者一看就知道这人是谁）
- 目标与身份严重冲突（不是小冲突，是完全反着来）
- 反差本身暗示引擎（怎么可能？就看他怎么做到）

### 模式3：倒计时型

**公式**：「世界观：XX天后，我就要死了」

**核心**：明确的时间压力，制造紧迫感和阅读紧张度。

**示例**：
- 三国：我是董卓，还有三天可活
- 火影：我得了绝症，只剩一年
- 斗破：废材体质觉醒倒计时，三个月

**要素**：
- 明确的时间期限（天/月/年）
- 到期后果严重（死亡/毁灭/不可逆）
- 暗示主角必须在期限内做什么

### 模式4：禁忌行为型

**公式**：「世界观：我做了XX禁忌之事」

**核心**：主角已经做了不该做的事，回不了头了。

**示例**：
- 海贼王：我偷吃了世界政府的秘密果实
- 火影：我复制了禁术卷轴的全部内容
- 仙侠：我吞了天道的气运

**要素**：
- 禁忌已经发生（不可撤销）
- 禁忌的后果是被追杀/被毁灭
- 禁忌同时也是力量来源（矛盾感）

### 模式5：反差错位型

**公式**：「世界观：在XX里，我却是YY」

**核心**：主角和世界的根本错位，制造天然冲突。

**示例**：
- 海贼王：在海军里，我有海贼的梦想
- 火影：在木叶，我是唯一不会忍术的人
- 红楼：在贾府，我是唯一知道结局的人

**要素**：
- 错位是结构性的（不是暂时的）
- 错位制造持续冲突（不是一次性尴尬）
- 错位暗示引擎（必须隐藏/必须适应/必须改变）

## 标题自检四问

生成标题后，必须回答以下四个问题：

### 1. 读者能在3秒内知道是什么类型的故事吗？

- ✅ 海贼王：我吃了手术果实 → 海贼王同人，关于恶魔果实
- ❌ 命运的漩涡 → 什么类型？完全不知道

### 2. 标题暗示了核心冲突/困境吗？

- ✅ ...但罗要杀我 → 有人要杀主角
- ❌ ...最强系统 → 没有冲突，只有设定

### 3. 标题能引发"怎么办"的好奇吗？

- ✅ 转生眼暴露，全族要灭口 → 读者想知道"他怎么活下来"
- ❌ 天才忍者之路 → 没有好奇心驱动

### 4. 标题对应的引擎是什么？能看出来吗？

- ✅ 武大郎，还有三天可活 → 引擎是倒计时
- ❌ 我在三国当霸主 → 看不出引擎是什么

**评分标准**：
- 4/4通过 = 好标题
- 3/4通过 = 可以用，但建议优化
- 2/4以下 = 必须重新设计

## 标题生成流程

### 步骤1：确定引擎类型
从 `creative_hooks.md` 的12种类型中确定引擎类型

### 步骤2：选择标题模式
从5种标题模式中选择最匹配的

### 步骤3：生成3-5个标题变体
每个变体用不同的措辞表达同一个核心困境

### 步骤4：四问自检
对每个变体进行四问自检

### 步骤5：用户选择
展示通过自检的标题供用户选择

### 示例流程

```
引擎类型：偷天换日型
标题模式：困境逆袭型

变体1：海贼王：我吃了手术果实，但罗要杀我
变体2：海贼王：偷了罗的果实，现在他要我的命
变体3：海贼王：吃了不该吃的果实，罗的追杀开始了

四问自检：
变体1 → 4/4 ✅
变体2 → 4/4 ✅
变体3 → 3/4 ⚠️（"不该吃"信息量不够明确）

推荐：变体1
```
