## 角色塑造基本原则

### 核心原则：拒绝脸谱化

- ❌ 错误：老鼠只是"阴险狡诈"，蒙卡只是"暴躁残暴"
- ✅ 正确：老鼠阴险狡诈但多疑，蒙卡暴躁残暴但也讲道理（前提是对方实力足够）

### 角色塑造三要素

1. **性格核心**：角色的核心性格特征
2. **行为逻辑**：角色如何根据自己的性格做出决策
3. **情感变化**：角色在不同情境下的情感反应

## 角色性格模板

### 主角性格模板

```yaml
核心性格: 危机隐忍→谋划分果实→加点变强→蝴蝶效应→霸权碾压
表面性格vs真实性格:
  表面（开局）: 普通海军小兵，胆小怕事
  真实（开局）: 步步为营，拜师学习，谋划果实
  真实（中期）: 学习成功，加点变强，收服强敌
  真实（后期）: 霸权碾压，势不可挡
```

### 反派性格模板

#### 1. 阴险狡诈型（如老鼠上校）

**性格特征**：
- 多疑：不会轻易相信任何人
- 狡猾：喜欢用计谋，不正面硬碰硬
- 冷静：遇事不慌，先思考再行动

**行为逻辑**：
- 发现异常 → 先派人调查 → 确认信息 → 制定计划 → 缓慢执行
- 遇到强敌 → 暂时退让 → 寻找机会 → 暗中破坏 → 最终复仇

**示例情节点**：
```markdown
【老鼠的怀疑】逃回的亲信向老鼠汇报：在谢尔兹镇遇到了伏击，而且有一个蒙卡士兵"略知老鼠内部情况"。老鼠眯起眼睛，阴冷地问："略知内部？老鼠内部只有我的心腹才知道这些，他是怎么知道的？"亲信说："俘虏说那个士兵是蒙卡的手下，但说话的语气和知道的细节都很像我们的人..."
【老鼠的推断】老鼠生性多疑阴险，立刻推断：李寒可能是老鼠内部派去的卧底，现在已经在蒙卡那边获得了信任，正在两头讨好。老鼠冷笑："聪明人喜欢两头下注，但两头都下注的人，往往死得最快。"
```

**对话风格**：
- 语气：阴冷、沉稳
- 特点：喜欢用反问句，试探对方
- 示例："你真的是来帮忙的吗？"

#### 2. 暴躁残暴型（如蒙卡）

**性格特征**：
- 暴躁：一言不合就发火
- 残暴：对敌人毫不留情
- 傲慢：看不起弱者

**行为逻辑**：
- 遇到挑衅 → 立刻暴怒 → 直接攻击 → 不留活口
- 遇到强者 → 先评估实力 → 实力不足则退让 → 等待机会 → 再次挑战

**示例情节点**：
```markdown
【蒙卡的暴怒反击】老鼠的"假海贼"袭击了蒙卡的补给船，蒙卡暴怒："海贼？老子在东海杀了多少海贼，还怕几只小老鼠？"蒙卡直接率军袭击老鼠在橘子镇的据点，双方爆发正面冲突，死伤惨重
```

**对话风格**：
- 语气：暴躁、粗鲁
- 特点：喜欢用感叹号，大喊大叫
- 示例："海贼？老子杀你们如杀鸡！"

#### 3. 高傲冷傲型（如索隆）

**性格特征**：
- 高傲：看不起弱者
- 冷傲：话少，但一针见血
- 固执：认定的目标不会改变

**行为逻辑**：
- 遇到挑战 → 接受挑战 → 全力以赴 → 赢则不屑，输则认栽 → 继续变强

**示例情节点**：
```markdown
【索隆的挑战】索隆眼中闪过战意："切磋？好啊！我正好想看看师傅的新徒弟有什么本事。"索隆拔出两把刀（和道一文字、三代鬼彻的前身），摆好架势："来吧！"
```

**对话风格**：
- 语气：冷淡、自信
- 特点：话少，但每句话都有力
- 示例："你的实力不错，但我不会输给你。"

#### 4. 吹牛谨慎型（如乌索普）

**性格特征**：
- 吹牛：喜欢夸大自己的能力
- 谨慎：真正遇到危险时会害怕
- 善良：关键时刻会保护朋友

**行为逻辑**：
- 正常情况 → 吹牛说大话 → 遇到危险 → 吓得逃跑 → 关键时刻 → 鼓起勇气 → 保护朋友

**示例情节点**：
```markdown
【乌索普的吹牛】可雅活下来后，乌索普吹牛说："哈哈，这是我的计划！我早就知道克洛船长要害可雅，我安排了人手保护她！李寒和索隆都是我请来的帮手！"
```

**对话风格**：
- 语气：夸张、搞笑
- 特点：喜欢用"我是"、"我做到了"等自我吹嘘的表达
- 示例："我是海上的勇士，没有我做不到的事！"

#### 5. 绅士猥琐型（如山治）

**性格特征**：
- 绅士：对女性尊重、礼貌
- 猥琐：对美女过度热情
- 坚定：有梦想，有原则

**行为逻辑**：
- 遇到美女 → 立刻绅士 → 展示厨艺 → 邀请吃饭 → 遇到危险 → 保护女性 → 战斗中 → 用腿攻击

**示例情节点**：
```markdown
【山治的梦想】乌索普听到山治的自言自语："我要找到伟大航路的All Blue，那是厨师的天堂。"乌索普暗想：这个厨师也有梦想啊
```

**对话风格**：
- 语气：温柔、礼貌（对女性）
- 特点：喜欢用"小姐"、"女士"等称呼
- 示例："小姐，这是为您准备的美食。"

#### 6. 聪明坚强型（如娜美）

**性格特征**：
- 聪明：善于谋略、理财
- 坚强：面对困境不放弃
- 独立：不依赖他人

**行为逻辑**：
- 遇到困境 → 分析情况 → 制定计划 → 独立解决 → 遇到困难 → 咬牙坚持 → 最终成功

**示例情节点**：
```markdown
【娜美的痛苦】山治看到娜美的痛苦，娜美说："我想救村民，但我必须留在阿龙海贼团，才能收集钱买下可可亚西村。"山治问："你需要多少钱？"娜美说："一亿贝利。"山治震惊："这么多！"
```

**对话风格**：
- 语气：理性、冷静
- 特点：说话直接，不拐弯抹角
- 示例："我需要一亿贝利，你能帮我吗？"

## 角色行为逻辑

### 主角行为逻辑

```yaml
危机情境: 绝境思考 → 编造谎言 → 提供价值 → 暂时脱险
发展情境: 拜师学习 → 获得技能 → 系统加点 → 实力提升
收服情境: 派人观察 → 了解困境 → 提供价值 → 展示实力 → 成功收服
```

### 反派行为逻辑

```yaml
阴险狡诈型:
  怀疑: 派人调查 → 验证信息 → 制定计划 → 暗中破坏
  复仇: 暂时退让 → 寻找机会 → 暗中破坏 → 最终复仇

暴躁残暴型:
  挑衅: 立刻暴怒 → 直接攻击 → 不留活口
  战败: 评估实力 → 退让 → 等待机会 → 再次挑战
```

```yaml
索隆:
  遇到挑战: 接受 → 全力以赴 → 赢则不屑，输则认栽 → 继续变强

乌索普:
  正常情况: 吹牛说大话 → 遇到危险 → 吓得逃跑 → 关键时刻 → 鼓起勇气
  收服过程: 遇到困难 → 李寒帮助 → 震撼实力 → 考虑加入 → 最终加入

山治:
  遇到女性: 立刻绅士 → 展示厨艺 → 邀请吃饭
  收服过程: 保护哲普 → 李寒帮忙 → 震撼实力 → 考虑加入 → 最终加入

娜美:
  遇到困境: 分析情况 → 制定计划 → 独立解决
  收服过程: 保护村民 → 李寒帮助 → 震撼实力 → 考虑加入 → 最终加入
```

## 角色互动模式

### 索隆 vs 乌索普

```markdown
【索隆和乌索普的互动】索隆对乌索普说："你的射击技术不错，但你的胆子太小了。"乌索普反驳："我不是胆小，我是谨慎！谨慎才能活得更久！"索隆冷笑："谨慎？我靠实力变强，不靠谨慎。"李寒看着两人争论，觉得有趣：这两个家伙性格互补，但关系会越来越好
```

**互动特点**：性格互补，互相吐槽，但关系越来越好

### 索隆 vs 山治

```markdown
【索隆和山治的互动】索隆对山治说："你的腿法不错，但你的性格太猥琐了。"山治愤怒："你说什么？你才是色鬼！"索隆冷笑："我和娜美、罗宾握手是礼貌，你那是猥琐。"两人开始争吵，李寒看着两人争论，觉得有趣：这两个家伙性格不合，但关系会越来越好
```

**互动特点**：性格不合，经常争吵，但关键时刻互相配合

## 质量检查清单

在编写角色相关内容时，必须检查以下项目：

- [ ] 角色行动符合性格设定
- [ ] 角色对话风格一致
- [ ] 角色情感变化合理
- [ ] 角色互动有逻辑
- [ ] 没有脸谱化描写
- [ ] 反派有合理的行动逻辑
- [ ] 同盟者有合理的收服过程
