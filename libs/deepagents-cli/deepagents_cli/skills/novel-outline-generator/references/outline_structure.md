## 概览
本文档定义高质量小说大纲的标准结构，适用于海贼王同人小说等长篇网络小说创作。大纲需要兼顾剧情逻辑、角色发展、读者体验（爽点、钩子）和伏笔布局。

## 整体结构

### 必需部分
1. **小说基础信息**：世界观、主角、金手指、风格定位等
2. **系统设定**（如有）：金手指的功能、规则、限制
3. **主角角色卡**：外貌、性格、能力、背景
4. **故事线结构**：
   - 分卷概述
   - 详细章节（每章包含：概述、情节点、情感变化、爽点、钩子、伏笔）

### 示例框架
```markdown

[基础信息字段]

[系统设定详情]
```

## 卷概述规范

### 必需字段
- **核心主题**：本卷探讨的核心议题（如"成长"、"复仇"、"自由"等）
- **核心冲突**：主角面临的主要矛盾（如 vs 反派势力、vs 自身局限）
- **主角目标**：本卷主角想要达成什么
- **本卷收获**：本卷结束后，主角获得了什么（力量、势力、盟友、资源、成长）
- **关键事件**：本卷的关键转折点（3-5个）

### 质量要求
- **逻辑清晰**：核心冲突能支撑整个卷的剧情走向
- **目标明确**：主角目标具体、可衡量
- **成长合理**：本卷收获符合成长曲线，不过度跳跃
- **节奏把控**：关键事件分布合理，有起伏

### 示例
```
#### 卷概述
**核心主题**: 初入海军，从底层崛起的奋斗史
**核心冲突**: 体制内的等级森严 vs 主角的快速晋升野心
**主角目标**: 在谢尔兹镇建立初步势力基础，晋升到伍长级别
**本卷收获**: 获得第一个军衔晋升、收服第一批手下（老鼠等）、初步建立影响力
**关键事件**:
1. 招募索隆入伙
2. 处理老鼠事件，获得蒙卡认可
3. 晋升为一等兵
4. 遭遇索隆，收服其为手下
5. 娜美和乌索普来访，建立初步合作关系
```

## 章节概述规范

### 必需字段
- **章节概述**：用1-3句话概括本章核心内容
- **情节点**：3-7个具体情节点，构成本章主要情节
- **情感变化**：主角在本章的情感轨迹（如：期待→惊讶→兴奋）
- **爽点**：本章让读者感到爽快的情节（1-2个）
- **钩子**：引发读者好奇，想看下一章的问题或悬念
- **伏笔**：为后续剧情埋下的线索（0-2个）

### 质量要求
- **概述简洁**：1-3句话说清本章内容
- **情节点具体**：避免"获得"、"遇到"等模糊表述，要有具体的人物、动作、结果
- **情感轨迹清晰**：情感变化符合逻辑，有起承转合
- **爽点明确**：爽点要具体（不是"主角变强"而是"主角晋升为一等兵，系统获得3点能量"）
- **钩子有效**：钩子要引发真实的好奇（如"索隆提出一个奇怪的要求"比"主角面临挑战"更有效）
- **伏笔自然**：伏笔不经意间植入，不是强行标注

### 示例
```markdown
### 第3章：《意外的收获》

**章节概述**: 主角在处理老鼠事件时展现卓越能力，获得蒙卡认可，晋升为一等兵。

**情节点**:
1. 【老鼠事件】主角发现老鼠偷运海军物资，没有直接抓捕，而是暗中收集证据
2. 【巧妙利用】主角利用证据威胁老鼠，老鼠提出"合作"，愿意分享情报
3. 【情报价值】老鼠提供的情报指向海贼猎人索隆，主角看到收服机会
4. 【正式行动】主角向蒙卡汇报，蒙卡决定派主角处理索隆
5. 【意外收获】蒙卡对主角的表现非常满意，当场宣布晋升为一等兵

**情感变化**: 紧张（计划是否成功）→ 意外（老鼠主动合作）→ 兴奋（获得晋升）

**爽点**:
1. 主角利用智慧而非武力解决问题，展现能力
2. 蒙卡对主角刮目相看，当场晋升，系统获得3点能量

**钩子**: 蒙卡交给主角一个新任务："去处理那个索隆，不过别杀他，我有其他打算"

**伏笔**:
1. 老鼠提到"有人想对付蒙卡"，暗示谢尔兹镇有第三方势力
```

## 情节点规范

### 结构要求
每个情节点采用格式：`【小标题】具体描述`

- **小标题**：2-6字，概括情节点核心
- **具体描述**：50-200字，描述具体的人物、动作、结果

### 质量要求
1. **具体化**：
   - ❌ 错误："主角获得势力"
   - ✅ 正确："李寒主动向准将请示，组织临时海军部队维持秩序。准将看到李寒能力出众，临时任命李寒负责谢尔兹镇的海军事务。李寒利用这个机会，收服了一些老鼠和蒙卡的手下（这些人都是墙头草，看到李寒已经是一等兵，主动投靠）"

2. **有细节**：
   - ❌ 错误："主角与索隆战斗"
   - ✅ 正确："主角与索隆在基地广场交锋。索隆使用三刀流，主角用霸气压制。两人激战数百回合后，索隆意识到差距，主动认输，提出加入主角麾下"

3. **符合角色逻辑**：
   - 主角行为要符合其性格设定
   - 配角行为要符合其在原作品中的设定（海贼王同人需保持角色原汁原味）

4. **因果关系明确**：前一个情节点为后一个铺垫，不是孤立事件

### 禁止模式
- ❌ "获得军功" → 应具体说明如何获得、谁认可
- ❌ "获得势力" → 应具体说明收服了谁、如何收服
- ❌ "李寒发现能量" → 应具体说明发现过程，让读者觉得自然
- ❌ "收服索隆" → 应具体说明过程，符合索隆的性格（不会轻易被收服）

## 辅助元素规范

### 情感变化
- 格式：`状态1 → 状态2 → 状态3`
- 要求：
  - 情感变化要与情节点对应
  - 每章情感轨迹要有起伏（不能一直平淡）
  - 情感词汇要具体（如"期待"、"惊讶"、"兴奋"、"担忧"等）

### 爽点
- 定义：让读者感到爽快、满足的情节
- 类型：
  1. **能力提升爽**：晋升、获得新能力、技能升级
  2. **势力扩张爽**：收服高手、获得地位
  3. **智力碾压爽**：用智慧解决问题，让他人刮目相看
  4. **打脸爽**：看不起主角的人被打脸
- 要求：
  - 每章至少1个爽点（可以是小爽点）
  - 爽点要铺垫到位，不能突如其来
  - 爽点要具体（不是"主角变强"而是"主角晋升为一等兵"）

### 钩子
- 定义：引发读者好奇，想看下一章的问题或悬念
- 类型：
  1. **问题型**："谁会来挑战主角？"
  2. **悬念型**："主角会做出什么选择？"
  3. **反转型**："某个角色提出意外要求"
- 要求：
  - 每章必须有1个有效钩子
  - 钩子要具体，不能笼统
  - 钩子要引发真实的好奇心

### 伏笔
- 定义：为后续剧情埋下的线索
- 类型：
  1. **剧情伏笔**：暗示后续事件（如"有人想对付蒙卡"）
  2. **角色伏笔**：暗示角色身份或背景（如"索隆的身世"）
  3. **力量伏笔**：暗示后续获得能力或资源
- 要求：
  - 伏笔要自然植入，不能强行标注
  - 伏笔要有回响（后续剧情要回应）
  - 不是每章都需要伏笔（0-2个）

## 质量检查清单

### 卷概述检查
- [ ] 核心主题明确
- [ ] 核心冲突清晰
- [ ] 主角目标具体可衡量
- [ ] 本卷收获合理（不过度跳跃）
- [ ] 关键事件分布合理（3-5个）

### 章节概述检查
- [ ] 章节概述简洁（1-3句话）
- [ ] 情节点具体（3-7个，每个50-200字）
- [ ] 情节点禁止模糊表述（"获得"、"遇到"等）
- [ ] 情感变化有起伏
- [ ] 爽点具体（至少1个）
- [ ] 钩子有效（引发好奇）
- [ ] 伏笔自然（如有）

### 逻辑一致性检查
- [ ] 情节点之间有因果关系
- [ ] 角色行为符合其性格设定
- [ ] 配角行为符合原作设定（海贼王同人）
- [ ] 没有逻辑矛盾（时间线、资源、能力）

### 读者体验检查
- [ ] 节奏合理（不拖沓也不过快）
- [ ] 爽点分布均匀（每章至少1个）
- [ ] 钩子有效（引发继续阅读的欲望）
- [ ] 伏笔回应（有埋有收）

## 示例：完整章节

```markdown
### 第5章：《索隆的加入》

**章节概述**: 主角与索隆交战后收服其为手下，娜美和乌索普来访。

**情节点**:
1. 【交手】主角与索隆在基地广场交锋。索隆使用三刀流，主角用霸气压制
2. 【差距】两人激战数百回合后，索隆意识到差距，主动认输
3. 【提议】索隆提出一个要求："我可以加入你，但你必须带我去伟大航路"
4. 【协议】主角答应："可以，但你要先为我效力一年"。索隆同意
5. 【访客】娜美和乌索普来到谢尔兹镇，寻求与主角合作
6. 【合作】主角看出娜美和乌索普的价值，提出合作方案："你们可以借助我的海军身份，在东海活动，但要为我提供情报"

**情感变化**: 期待（与索隆交战）→ 惊讶（索隆主动认输）→ 满意（收服成功）→ 意外（娜美和乌索普来访）

**爽点**:
1. 主角压制索隆，展现霸气实力
2. 成功收服索隆，势力扩张

**钩子**: 娜美说："我们想合作，但你需要帮我们处理一个人"

**伏笔**:
1. 娜美和乌索普提到的那个人，可能是阿龙（后续反派）
```
