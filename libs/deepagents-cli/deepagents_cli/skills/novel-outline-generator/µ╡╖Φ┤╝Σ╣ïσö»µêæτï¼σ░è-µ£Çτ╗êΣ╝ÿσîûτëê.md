## 深蓝系统设定（最终版）

### 唯一功能：给已获得的技能加点

```
深蓝系统 = 加点系统
唯一作用：给已经获得的技能加点，让技能变强
```

### 加点规则

**技能变强**:
```
技能等级: 入门 → 熟练 → 精通 → 大师 → 宗师 → 极境
加点效果: 技能变强，从入门到极境
```

**可加点的技能**:
- 剑术（需要先学习）
- 六式（需要先学习）
- 霸气（需要先修炼）
- 恶魔果实（需要先吃下）
- 体术/格斗（需要先学习）
- 航海术（需要先学习）
- 枪械/射击（需要先学习）
- 等等

**不能加点的**:
- ❌ 权谋（抽象概念）
- ❌ 智慧（抽象概念）
- ❌ 领导力（抽象概念）
- ❌ 运气（抽象概念）
- ❌ 未获得的技能（必须先获得才能加点）

## 第一卷：间谍求生与系统觉醒（1-20章）

### 第1章：《码头上的目击者》
**章节概述**: 李寒刚穿越，在码头执行采购任务时意外目击老鼠上校与鱼人的交易，被发现后距离被灭口只剩3分钟，必须在生死关头想出求生之道。

**情节点**:
1. 【穿越】李寒在码头货箱后醒来，发现自己穿越成老鼠部队三等兵，正在橘子镇执行采购任务
2. 【目击交易】无意中看到老鼠上校与阿龙的鱼人部下在交易——金贝与毒品
3. 【惊慌碰箱】李寒意识到自己撞见了不该看的秘密，惊慌中不小心碰倒货箱发出声响
4. 【被鱼人抓住】鱼人瞬移过来，掐住李寒的脖子。老鼠上校冷眼:"不是我们的人，处理掉。"——距离被"灭口"只剩3分钟
5. 【绝境思考】李寒拼命开动脑筋，在鱼人准备动手前突然大喊:"等等！我是蒙卡上校的部下！"
6. 【身份利用】老鼠眼神一凝，但依然谨慎:"说清楚，你是什么人？为什么在这里？"李寒抓住机会:"我是蒙卡上校手下的三等兵，被派来橘子镇采购物资。刚才在码头等船时，无意中听到两个同僚在谈论'调查老鼠上校'的事！"——利用自己真实身份，但编造"听到同僚谈话"的谎言
7. 【提供价值】老鼠追问:"你听到了什么？他们是谁？"李寒快速思考，说:"我只听到了一部分，他们说'调查进展'、'证据'、'三天后行动'什么的，但我没听全，而且他们发现我在偷听，立刻走了。不过，我认识他们，都是我们支部的士兵，我可以回去打探消息！"——提供"可以打探消息"的价值
8. 【老鼠的半信半疑】老鼠半信半疑，但考虑到:①李寒确实是蒙卡的手下（可以验证身份）②李寒"听到了部分信息"而且"认识那些士兵"（可以接近获取信息）③如果蒙卡真的在调查，他需要有人在蒙卡身边做内应。老鼠决定暂时不杀李寒，派人监视

**情感变化**: 穿越懵逼→目击震惊→惊慌碰箱→被抓住恐惧→绝境思考→身份利用→提供价值→半信半疑（险中求活，但压力巨大）
**爽点**: 纯靠智慧自救的紧张感，利用真实身份增加可信度的巧妙感
**钩子**: 李寒如何证明价值？蒙卡调查老鼠是真是假？老鼠会发现他是编的吗？
**伏笔**:
- 李寒的真实身份（蒙卡手下的三等兵）
- 被迫成为间谍的处境（后续需要应对双重身份）
- 老鼠的疑心（随时可能被识破的风险）
- 监视者的存在（增加紧张感和后续冲突点）

### 第2章：《成为间谍与系统激活》
**章节概述**: 李寒利用真实身份优势，说服老鼠让自己成为间谍，但在精神高度紧绷下忽略了系统提示，直到放松下来才发现深蓝系统已激活。

**情节点**:
1. 【继续说服】李寒继续发挥智慧，详细说明自己作为蒙卡手下三等兵的优势:"我可以自由进出谢尔兹镇的海军基地，可以接近蒙卡上校和贝鲁梅伯，可以听到各种内部消息。而且，我身份低微，不会引起怀疑。"——利用真实身份的优势说服老鼠
2. 【老鼠的考量】老鼠思考后，认为李寒确实有利用价值:①身份真实，可以验证；②地位低微，不会引起怀疑；③可以接近蒙卡和贝鲁梅伯；④如果蒙卡真的在调查，李寒是最好的内应。老鼠决定:"好，我同意。你回去后，定期向我汇报蒙卡那边的动向。我会派人送你回去，确保你安全到达。"
3. 【系统提示被忽略】就在老鼠同意让李寒成为间谍的瞬间，李寒脑海中似乎闪过一个声音，但他精神高度紧绷，完全没注意到——系统提示被忽略了
4. 【上船离开】老鼠派心腹士兵（监视者）护送李寒上船，准备返回谢尔兹镇。李寒表面上配合，内心却在思考如何应对双重身份的压力
5. 【海上航行】船在海上航行，李寒坐在船舱里，精神依然紧绷，思考着回到谢尔兹镇后如何应对——既要应付蒙卡，又要应付老鼠，还要编造情报
6. 【放松与发现】晚上，李寒终于放下心来——至少暂时活下来了。就在他放松的瞬间，突然发现脑海中出现了一个系统界面:"深蓝加点系统已激活！当前身份:间谍（双重身份），基础能量:10点。"——系统在成为间谍时就已经激活，但主角精神紧绷没注意到，现在放松下来才发现
7. 【系统研究】李寒开始研究系统，发现系统有个人身体信息，还有技能列表:射击、劈砍（都是基础技能）。他尝试将意识放到技能加号上，发现需要消耗能量才能加点，但能量只有10点，只能加点一两次

**情感变化**: 说服压力→老鼠考量→系统提示被忽略→上船离开→海上航行（精神紧绷）→放松下来→发现系统激活的惊喜
**爽点**: 说服成功的成就感+系统激活的惊喜感（延迟发现更有爽感）
**钩子**: 系统有什么功能？李寒如何使用系统？回到谢尔兹镇后如何应对双重身份？如何编造情报？
**伏笔**:
- 系统激活条件（成为间谍时激活，但主角没注意到）
- 双重身份的压力（后续需要应对）
- 监视者的存在（后续可能成为冲突点或可利用的棋子）
- 系统功能（为后续使用做铺垫）

**章节概述**: 李寒回到谢尔兹镇，老鼠给了他电话虫用于联系，李寒看到贝鲁梅伯在码头，主动接近假装熟悉，让监视者看到他和贝鲁梅伯"很熟"，老鼠终于放下心来。
