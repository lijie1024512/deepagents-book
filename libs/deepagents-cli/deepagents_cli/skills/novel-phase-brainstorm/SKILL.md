# 阶段1：脑洞构思

## 任务目标
确定小说的基础方向：类型、核心吸引力、参考案例。

## 步骤

### 1. 确定小说类型
提供选择：
```
A. 同人小说（海贼王/火影/死神等）
   - 有现成世界观，重点在改变和蝴蝶效应
B. 原创小说（玄幻/都市/历史等）
   - 需要设计世界观，更自由但工作量大
C. 轻改小说（基于某部作品但大幅修改）
   - 借用部分设定，创造新故事
```

### 2. 确定核心吸引力
提供选择（可多选）：
```
A. 逆袭与成长 — 从弱到强的蜕变
B. 智谋与博弈 — 计中计、信息差、局势逆转
C. 情感与羁绊 — 同伴情、师徒情、爱情
D. 探索与发现 — 世界的秘密、角色的过去
💡 最好的故事是2-3种吸引力的组合
```

### 3. 收集用户想法和设定

用自然对话收集用户脑中已有的想法（不强制，用户没想法也可以跳过）：
```
关于你心目中的故事，有没有一些初步想法？
A. 有一些设定/角色/情节的想法（说说看，多少都行）
B. 只有大致方向，具体没想好
C. 完全没想法，希望你帮我设计
```

> 收集到的想法按优先级标注，供引擎阶段使用：
> - ★ 核心设定（用户反复强调的） → 必须融入
> - ☆ 偏好设定（提过但没强调的） → 尽量融入，可调整
> - ○ 开放设定（未指定的） → 由创意决定

### 4. 收集参考案例
```
A. 我有推荐的好书（提供书名或本地文件路径）
B. 我知道一些书名，但没有文件
C. 帮我搜索这个世界观下的热门作品
D. 不需要参考，直接开始设计
```

> 选择A：读取本地文件，提取风格和引擎模式，保存到 `style_notes.md`
> 选择B：网络搜索免费章节/书评/讨论帖，保存到 `style_notes.md`
> 选择C：搜索该世界观热门同人排行榜，展示3-5条关键发现

## 完成标志
- 用户明确选择了小说类型
- 用户明确选择了核心吸引力
- 用户想法已收集并标注优先级（或用户选择跳过）
- 参考案例已收集（或用户选择跳过）

## 推进时机
当以上各项都确认后：
```python
advance_phase("engine", "脑洞阶段完成：类型={类型}，吸引力={吸引力}")
```

## 输出格式
将确认的信息记录到 memory：
```python
remember("decision", "小说类型", "海贼王同人")
remember("decision", "核心吸引力", "智谋与博弈 + 情感与羁绊")
remember("decision", "用户设定", "★海军阵营 ☆收势力 ○金手指类型待定")
remember("decision", "参考案例", "武大郎、汉末魅魔")
```

## 禁止事项
- ❌ 跳过吸引力选择直接设计引擎
- ❌ 一次推进到 character 或更后的阶段
- ❌ 在用户未确认前自动推进
- ❌ 把用户的所有设定都当作硬性约束（设定是参考材料，不是模具）
