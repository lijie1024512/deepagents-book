# 阶段6：修订润色

## 目标
从多个维度诊断和优化已完成的正文。

## 前置读取
- 读取已完成章节正文
- 读取 `engine.md` → 检查引擎一致性
- `list_characters()` → 检查角色一致性

## 诊断维度

1. **引擎一致性**：每章冲突能回溯到引擎吗？有无随机冲突？冲突在递进还是转圈？
2. **画面感**：有无"机制说明"式描写？关键场景有感官描写吗？
3. **叙事结构**：起承转合完整吗？比例合理吗？
4. **情感曲线**：抑扬平衡（约4:6）？有无全程高爽或持续压抑？
5. **角色一致性**：内在矛盾持续体现？对话符合性格？
6. **展现vs告诉**：有无旁白说明角色心理？

## 操作流程

1. 用户指定诊断范围（章节或全卷）
2. 执行诊断，生成报告
3. 每个问题提供2-3个修改方案
4. 用户选择后执行修改，展示前后对比
