# 角色卡模板

## 角色卡基础格式

```
【基本信息】
姓名:
年龄:
性别:
种族:
身份:
所属势力:
外貌特征:

【力量属性】
灵压/查克拉/霸气等级:
能力类型:
特长领域:
弱点:

【特殊能力】
金手指/果实/忍术/斩魄刀:
能力描述:
使用限制:
成长潜力:

【性格深度】
核心性格:一句话概括核心性格（如"危机隐忍→谋划分果实→加点变强→霸权碾压"）
表面性格vs真实性格:
  - 表面（开局）:普通海军小兵，胆小怕事，点头哈腰
  - 真实（开局）:步步为营，暗中布局，观察局势
  - 真实（中期）:谋划成功，收割战果，建立势力
  - 真实（后期）:霸权碾压，势不可挡，不怒自威
行为习惯（小动作、癖好）:
  - 紧张时:无意识地敲击手指、低头掩饰表情
  - 思考时:闭眼深呼吸、整理衣领
  - 爽快时:嘴角微扬、眼神锐利
  - 爆发时:不怒自威、气场外露
口头禅/说话风格:
  - 对上级（开局）:"是，长官，我明白。"（恭敬）
  - 对同级（中期）:"我们合作。"（平等）
  - 对敌人（后期）:"滚，别挡我的路。"（冷冽）
价值观:
  - 核心价值观:活下去，谋划果实，往上爬
  - 次级价值观:隐忍是为了谋划，谋划是为了加点，加点是为了变强
  - 矛盾点:开局隐忍vs后期碾压（需要逐步转变）
人性弱点:
  - 对死的恐惧（开局）:极度害怕死，求生欲极强
  - 对变强的渴望（中期）:想加点变强，想往上爬
  - 对权力的渴望（后期）:往上爬的执念，霸权的欲望
情感表达方式:
  - 不会轻易表露真实情感
  - 内心戏丰富，但表面冷静
  - 偶尔会流露真情（对盟友）
内心矛盾:
  - 隐忍vs爆发（前期压抑，后期爆发）
  - 信任vs利用（盟友是真的盟友还是棋子）
  - 理智vs情感（关键时刻的抉择）
成长轨迹:危机求生→拜师学习→加点变强→收服强敌→改变世界→霸权碾压

【背景故事】
出身:现代地球普通青年，喜欢看海贼王，知道所有剧情和技能获取地点。不是天才，但很聪明，擅长谋划和布局。
成长经历:
  - 穿越:醒来发现自己穿越成老鼠部队三等兵
  - 危机:意外发现老鼠和鱼人交易，被发现
  - 求生:编造谎言"蒙卡在调查老鼠"，活下来
  - 激活系统:深蓝系统激活，但精神紧绷没注意到
  - 开始布局:利用先知能力，谋划技能和果实
关键转折:
  - 穿越第一天:码头目击交易，差点被灭口
  - 系统激活:精神放松后才发现系统已激活
  - 拜师学习:拜师耕四郎学习剑术，获得首个技能
  - 收服索隆:改变原著走向，蝴蝶效应开始
当前状态:三等兵，深蓝能量10点，成为老鼠的间谍，暗中谋划

【角色定位】
小说中的作用:
与原著关系:
对剧情的影响:
主要对手:

【成长路线】
当前阶段:
短期目标:
中期目标:
长期目标:
预期最终状态:

【技能清单】
核心技能:
辅助技能:
特殊技能:
禁术/绝招:

【装备物品】
武器:
饰品:
宝物:
特殊物品:

【人际关系】
盟友:
对手:
恋人/伴侣:
家人:
导师:

【角色深度】
为什么这个角色会这样？
他的核心动机是什么？
他最害怕失去什么？
他最渴望得到什么？
他最大的矛盾是什么？
```

## 角色卡示例

### 示例1：海贼王角色卡
```
【基本信息】
姓名:罗恩
年龄:19岁
性别:男
种族:人类
身份:穿越者、船长
所属势力:星辰大海贼团（原创）
外貌特征:银发蓝眼，身材修长，穿着黑色风衣

【力量属性】
霸气等级:三色霸气（见闻色高阶、武装色中阶、霸王色初阶）
能力类型:霸气专精
特长领域:战斗智谋、布局规划
弱点:不会恶魔果实能力

【特殊能力】
金手指:
  - 先知:知晓原著剧情
  - 深蓝加点:可消耗灵魂碎片提升属性

能力描述:
  - 武装色霸气:可缠绕身体和武器，提升攻防
  - 见闻色霸气:可感知方圆5公里，预判攻击
  - 霸王色霸气:可震慑弱者，尚未掌握缠绕

使用限制:
  - 见闻色霸气消耗较大，连续使用会疲劳
  - 深蓝加点需要灵魂碎片，只能通过战斗或拯救灵魂获得

成长潜力:顶级（可达到四皇级）

【性格特点】
核心性格:冷静、智谋、有原则
行为风格:低调隐藏，关键时刻爆发
价值观:自由、正义、守护伙伴
人际关系:重情义，对朋友绝对信任
说话风格:简洁有力，不喜欢废话

【背景故事】
出身:现代地球
成长经历:穿越到海贼世界，获得先知能力
关键转折:决定改变原著悲剧
当前状态:刚刚出海，组建自己的海贼团

【角色定位】
小说中的作用:主角，改变海贼世界
与原著关系:不直接介入草帽团，作为平行线发展
对剧情的影响:蝴蝶效应改变多个篇章
主要对手:四皇、大将、世界政府

【成长路线】
当前阶段:东海篇，悬赏金5000万
短期目标:进入伟大航路，初步布局
中期目标:新世界，介入和之国
长期目标:成为海贼王，改变世界政府
预期最终状态:四皇级霸气，接近罗杰实力

【技能清单】
核心技能:
  - 武装色霸气（缠绕）
  - 见闻色霸气（预知未来雏形）
  - 霸王色霸气（震慑）

辅助技能:
  - 航海术
  - 战术规划
  - 谈判技巧

特殊技能:
  - 深蓝加点系统
  - 原著剧情预知

禁术/绝招:霸王色缠绕（未掌握）

【装备物品】
武器:名刀"夜空"（无上大快刀之一）
饰品:海贼王罗杰的草帽（捡到的）
宝物:历史正文碎片（空岛获得）
特殊物品:灵魂碎片收集器
```

## 不同金手指类型角色卡

### 深蓝加点类型
```
【特殊能力】
金手指:
  - 深蓝加点系统
  - 可查看属性面板
  - 可加点提升各项属性

属性面板:
  - 力量:XX/100
  - 敏捷:XX/100
  - 体质:XX/100
  - 智力:XX/100
  - 感知:XX/100
  - 运气:XX/100

加点规则:
  - 灵魂碎片兑换属性点
  - 每点提升对应属性1%
  - 特殊事件获得额外属性点

优势:均衡发展，无短板
劣势:需要大量灵魂碎片
```

### 系统面板类型
```
【特殊能力】
金手指:
  - 系统面板
  - 任务系统
  - 兑换系统
  - 技能学习

系统功能:
  - 日常任务:每日刷新
  - 主线任务:剧情推进
  - 隐藏任务:特殊触发
  - 兑换商城:技能、物品、血统

任务奖励:
  - 经验值
  - 系统点数
  - 特殊物品
  - 血统碎片

优势:功能丰富，成长路线明确
劣势:需要完成系统任务
```

### 转生类型
```

金手指:
  - 转生特定角色
  - 保留前世记忆
  - 身份优势

  - 转生为原著重要角色
  - 改变该角色命运
  - 保留原著能力
  - 获得新金手指

转生优势:
  - 身份优势，起步高
  - 原有人脉关系
  - 原有能力保留
  - 可直接改变剧情

优势:起点高，发展快
劣势:受限于原著身份
```

## 角色卡深度塑造示例

### 示例1:主角深度塑造
```
【性格深度】
核心性格:表面懦弱隐忍，内心冷酷无情，唯我独尊

表面性格vs真实性格:
  - 表面:唯唯诺诺的底层小兵，老鼠说什么就是什么
  - 真实:步步为营的幕后黑手，所有人都是棋子

行为习惯:
  - 表面习惯:低头说话，不敢直视上级
  - 真实习惯:左手大拇指无意识摩擦戒指（思考时会这样做）

口头禅/说话风格:
  - 对上级:"是，上校，我明白。"（语气卑微）
  - 对部下:"做好你该做的事。"（语气冷漠）
  - 对敌人:"你们没有资格知道我的计划。"（语气傲慢）

价值观:
  - 核心价值观:天下为棋局，众生为棋子
  - 次级价值观:自由至上，不接受任何束缚
  - 矛盾点:渴望自由，却又被力量欲望束缚

人性弱点:
  - 对掌控的渴望:无法容忍事情脱离控制
  - 对过去的执念:依然记得地球被压榨的痛苦
  - 情感软肋:虽然冷酷，但对真心对他的人会手下留情

情感表达方式:
  - 开心:嘴角微微上扬，眼神柔和
  - 愤怒:不说话，眼神冰冷
  - 悲伤:沉默，独自饮酒
  - 爱意:不会说出口，但会默默付出

内心矛盾:
  - 想要征服世界，又不想成为暴君
  - 想要真心爱人，又不敢完全信任
  - 想要改变世界，又害怕失去自我

成长轨迹:
  - 第一阶段:被社会压榨的肥宅，懦弱无能
  - 第二阶段:穿越初期，意识到可以改变
  - 第三阶段:开始布局，逐渐冷酷
  - 第四阶段:中期，情感与权力的矛盾
  - 第五阶段:后期，找到平衡，真正成为王者
```

### 示例2:反派深度塑造（老鼠上校）
```
【性格深度】
核心性格:表面贪婪残暴，内心有温情但被扭曲

表面性格vs真实性格:

  - 悲伤:独自哭泣
```

### 1. 角色定位
- 主角:核心推动剧情
- 配角:辅助主角或独立线
- 反派:提供冲突和挑战
- 原著角色:保持人设或合理改编

### 2. 能力平衡
- 不要过于强大（避免无敌流）
- 要有明显短板
- 成长要有节奏
- 能力要多样化

### 3. 性格魅力
- 性格要有特点
- 行为要有逻辑
- 价值观要清晰
- 要有成长空间

### 4. 人际关系
- 盟友:可信的伙伴
- 对手:势均力敌
- 恋人:感情线
- 家人:情感羁绊

### 5. 成长路线
- 要有明确目标
- 要有阶段划分
- 要有挑战和突破
- 要有收获和成就

## 角色卡使用说明
- 按模板填写基础信息
- 根据金手指类型调整特殊能力
- 保持角色性格一致
- 考虑与原著的关系
- 规划成长路线
- 设计人际关系
