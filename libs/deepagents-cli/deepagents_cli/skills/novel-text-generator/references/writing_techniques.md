## 描写金字塔

### 三层结构

```
        ┌─────────────┐
        │  情感共鸣   │  ← 顶层：让读者感同身受
        │  (内心)     │
        └──────┬──────┘
               │
        ┌──────┴──────┐
        │  感官细节   │  ← 中层：具体的感知体验
        │(视听触嗅味) │
        └──────┬──────┘
               │
        ┌──────┴──────┐
        │  基础叙述   │  ← 底层：发生了什么
        │  (事件)     │
        └─────────────┘

优质正文 = 三层交织
流水账 = 只有底层
```

### 层次说明

#### 底层：基础叙述
- **定义**：描述发生了什么事
- **作用**：推进情节，提供信息
- **特点**：客观、简洁、直接

**示例**：
```
李寒走进房间，看到索隆在练剑。
```

#### 中层：感官细节
- **定义**：通过五感让读者"身临其境"
- **作用**：增强画面感，让场景鲜活
- **五感**：视觉、听觉、触觉、嗅觉、味觉

**示例**：
```
推开斑驳的木门，一股汗水和铁锈混合的气息扑面而来。
昏暗的练武场中央，银色的刀光划破空气，嗡嗡的破空声震得耳膜发麻。
```

#### 顶层：情感共鸣
- **定义**：让读者感受角色的情感
- **作用**：建立情感连接，引发共鸣
- **方式**：内心独白、情绪描写、隐喻

**示例**：
```
李寒心中一凛——这家伙，比情报中描述的还要疯狂。
一种久违的战意在胸中燃烧，他的嘴角不自觉地上扬。
```

### 完整示例对比

**❌ 流水账（只有底层）**：
```
李寒走进了房间，看到了索隆，索隆正在练剑。李寒站在那里看了一会儿，
然后走了过去。索隆停下来，看着李寒。两人开始说话。
```

**✅ 优质正文（三层交织）**：
```
李寒推开斑驳的木门，一股汗水和铁锈混合的气息扑面而来。【感官-嗅觉】

昏暗的练武场中央，索隆赤裸着上身，三把刀在空气中划出银色的弧线，
嗡嗡的破空声震得李寒耳膜发麻。【感官-视觉+听觉】

汗珠从索隆青筋暴起的手臂上滚落，在地面砸出深色的印记。【感官-视觉】

李寒心中一凛——这家伙，比情报中描述的还要疯狂。【情感】

他没有出声，只是静静地站在门口，目光追随着那道道刀光。一种久违的
战意在胸中燃烧，他的嘴角不自觉地上扬。【情感+感官】

"站在那里看够了？"索隆头也不回，声音沙哑而冷淡。【叙述+感官-听觉】

"还行。"李寒迈步走进练武场，"不过，光是看可不过瘾。"【叙述】
```

## 感官描写技巧

### 视觉描写

**技巧**：
1. 光影对比：明暗、色彩对比
2. 动态捕捉：动作的轨迹和速度
3. 细节聚焦：特写关键物件或表情

**模板**：
```
- 光线/颜色：[阳光/月光/火光] + [颜色形容] + [照射方式]
- 动态：[主体] + [动作] + [轨迹/速度描述]
- 细节：[部位/物品] + [特征描述] + [暗示的含义]
```

**示例库**：
```
【光影】夕阳的余晖从窗缝中挤进来，在地面上划出一道血红的痕迹。
【动态】刀光如闪电般划过，在空气中留下一道肉眼可见的白痕。
【细节】索隆的眼角跳动了一下，那是他唯一的破绽。
```

### 听觉描写

**技巧**：
1. 声音拟态：用文字模拟声音
2. 声音对比：安静与喧闹、突然与持续
3. 声音含义：声音背后的情绪或信息

**模板**：
```
- 拟声：[声源] + [拟声词] + [声音特征]
- 对比：[环境音] + [突然的声音] + [反应]
- 含义：[声音描述] + [暗示的情绪/信息]
```

**示例库**：
```
【拟声】刀刃入肉的闷响让在场所有人都僵住了。
【对比】死一般的沉默中，一声轻笑突然响起，刺耳得让人牙酸。
【含义】他的声音平静得出奇，平静到让李寒后背发凉。
```

### 触觉描写

**技巧**：
1. 温度感知：冷热对比
2. 质感描写：粗糙、光滑、柔软
3. 痛感/快感：身体的直接感受

**模板**：
```
- 温度：[温度词] + [感受部位] + [反应/联想]
- 质感：[接触物] + [质感描述] + [感受]
- 痛感：[痛源] + [痛感描述] + [身体反应]
```

**示例库**：
```
【温度】海风裹挟着刺骨的寒意，像无数把小刀刮过脸颊。
【质感】剑柄被汗水浸透，握在手里有种黏腻的不适感。
【痛感】一阵剧痛从肋骨处炸开，疼得他眼前发黑。
```

### 嗅觉描写

**技巧**：
1. 气味识别：什么味道
2. 气味来源：暗示环境或情况
3. 气味联想：触发记忆或情绪

**示例库**：
```
【识别】空气中弥漫着血腥味，浓重得让人想呕吐。
【来源】一股硫磺的气息飘来，火山岛就在前方。
【联想】淡淡的烟草味让他想起了已故的师父。
```

### 味觉描写

**技巧**：
1. 直接品尝：食物、饮品
2. 隐喻味道：情绪的"味道"
3. 生理反应：嘴里的感觉

**示例库**：
```
【品尝】劣质的朗姆酒辛辣得像在喉咙里放了把火。
【隐喻】失败的苦涩在嘴里蔓延，怎么也咽不下去。
【生理】嘴里满是血腥味，牙齿似乎也松动了。
```

### 感官组合技巧

**规则**：每个场景至少使用2-3种感官

**示例**：
```
【视觉+听觉+触觉】
夕阳将海面染成一片金红，海浪拍打船舷的声音有节奏地响着。
李寒站在船头，海风将他的衣袍吹得猎猎作响，咸湿的水汽打在脸上，
带来一丝凉意。
```

## 情感渲染方法

### 直接情感描写

**方式**：直接描述角色的情绪

**模板**：
```
[角色] + 感到/觉得 + [情绪词] + [原因/表现]
```

**示例**：
```
李寒感到一阵愤怒涌上心头，拳头不自觉地握紧。
一种久违的兴奋在胸中燃烧，他已经很久没有遇到这样的对手了。
```

### 间接情感描写

**方式**：通过身体反应、动作、环境暗示情感

**技巧**：
1. **身体反应**：心跳加速、手心出汗、呼吸急促
2. **微表情/动作**：皱眉、攥拳、咬牙
3. **环境映射**：用环境描写暗示情绪

**示例**：
```
【身体反应】李寒的心跳陡然加速，血液仿佛都在沸腾。
【微动作】他的眼皮跳了跳，指节捏得咔咔作响。
【环境映射】天边的乌云越压越低，仿佛预示着即将到来的风暴。
```

### 内心独白

**方式**：展示角色的思维过程

**技巧**：
1. 简短有力：不要长篇大论
2. 符合角色：思维方式要符合角色性格
3. 推进情节：独白要有信息量

**示例**：
```
【分析型角色】
不对劲。李寒的眼睛微微眯起。这个老鼠，表面上唯唯诺诺，
但他的站位...是随时可以逃跑的方向。

【直觉型角色】
有危险！索隆的身体先于意识做出反应，刀已经挡在了身前。
```

### 情感节奏

**原则**：情感要有起伏，不能平铺直叙

**模式**：
```
平静 → 波动 → 高潮 → 回落

或

压抑 → 压抑 → 爆发 → 释放
```

**示例**：
```
【压抑阶段】
李寒站在原地，一言不发。周围的嘲笑声越来越大，但他的脸上
没有任何表情。

【爆发阶段】
"够了。"
李寒终于开口，声音不大，却让所有人都安静下来。
他抬起头，眼中是冰冷的杀意："既然你们这么想死..."

【释放阶段】
下一瞬，他已经出现在嘲笑最大声的那个人面前。
```

## 叙述与描写的平衡

### 比例建议

| 场景类型 | 叙述 | 描写 | 对话 |
|---------|------|------|------|
| 过渡场景 | 60% | 30% | 10% |
| 日常场景 | 30% | 30% | 40% |
| 紧张场景 | 20% | 50% | 30% |
| 战斗场景 | 30% | 50% | 20% |
| 对话场景 | 20% | 20% | 60% |

### 流水账检测规则

**触发警告的情况**：

1. **连续3句以上纯叙述**
   ```
   ❌ 李寒走进房间。他看到索隆。索隆在练剑。李寒走过去。
      索隆停下来。两人开始说话。
   ```

2. **没有感官描写**
   ```
   ❌ 整段文字都是"他做了什么"，没有任何感官细节
   ```

3. **对话无神态动作**
   ```
   ❌ "你好。"
      "你好。"
      "你来干什么？"
      "我来找你。"
   ```

### 修正方法

**原则**：每2-3句叙述后，加入描写

**示例**：
```
原文（流水账）：
李寒走进房间。他看到索隆在练剑。李寒站在那里看了一会儿。
索隆停下来看着他。

修正后：
李寒推开门，一股汗水和铁锈的气息扑面而来。【感官】
昏暗的练武场中央，索隆的刀光划出银色的弧线。【视觉】
李寒站在门口，目光追随着那道道刀光，嘴角微微上扬。【动作+情感】
"看够了？"索隆头也不回，声音沙哑而冷淡。【叙述+感官】
```

## 质量检查清单

### 描写金字塔检查

- [ ] 每个场景都有基础叙述（推进情节）
- [ ] 每个场景至少有2种感官描写
- [ ] 重要场景有情感共鸣描写
- [ ] 三层描写自然交织，不是机械堆砌

### 感官描写检查

- [ ] 使用了至少2种感官（视、听、触、嗅、味）
- [ ] 感官描写与场景氛围一致
- [ ] 感官描写有具体细节，不是泛泛而谈

### 情感渲染检查

- [ ] 情感描写方式多样（直接、间接、独白）
- [ ] 情感有起伏变化，不是平铺直叙
- [ ] 情感符合角色性格

### 叙述平衡检查

- [ ] 没有连续3句以上纯叙述
- [ ] 对话有神态动作配合
- [ ] 叙述与描写比例合适

## 常用描写词库

### 情绪词库

**正面情绪**：
- 兴奋、期待、满足、得意、释然、温暖、感动、敬佩

**负面情绪**：
- 愤怒、恐惧、绝望、焦虑、厌恶、悲伤、屈辱、嫉妒

**复杂情绪**：
- 纠结、矛盾、苦涩、怅然、复杂、五味杂陈

### 身体反应词库

**紧张**：心跳加速、手心出汗、呼吸急促、肌肉绷紧
**愤怒**：握拳、咬牙、青筋暴起、呼吸粗重
**恐惧**：发抖、僵硬、冷汗、腿软
**兴奋**：眼睛发亮、热血沸腾、摩拳擦掌

### 环境氛围词库

**紧张氛围**：压抑、沉闷、窒息、山雨欲来
**轻松氛围**：明媚、清新、温暖、惬意
**悲伤氛围**：阴沉、灰暗、凄凉、萧瑟
**神秘氛围**：朦胧、诡异、深不可测
