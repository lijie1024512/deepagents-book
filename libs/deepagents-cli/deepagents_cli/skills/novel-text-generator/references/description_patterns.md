## 环境描写模式

### 模式1：全景到特写

**结构**：大场景 → 中景 → 特写细节

**模板**：
```
[大场景概述]，[中景描述]。[特写细节]。
```

**示例**：
```
谢尔兹镇的码头在夕阳下染成一片金红，几艘破旧的渔船在波浪中轻轻摇晃。
系船柱上缠绕的绳索已经斑驳发黄，散发着海水浸泡后特有的腥咸气息。
```

---

### 模式2：感官叠加

**结构**：视觉 + 听觉 + 嗅觉/触觉

**模板**：
```
[视觉描述]，[听觉描述]。[嗅觉/触觉描述]。
```

**示例**：
```
练武场昏暗而空旷，只有窗户缝隙透进几道稀薄的光线。
刀剑碰撞的声音回荡在四壁，清脆而刺耳。
空气中弥漫着铁锈和汗水混合的气息，呛得人喉咙发紧。
```

---

### 模式3：动静结合

**结构**：静态背景 + 动态元素

**模板**：
```
[静态环境描述]。[突然的动态变化]。
```

**示例**：
```
海军基地的走廊空无一人，只有墙上的油灯在微微摇晃。
突然，一阵急促的脚步声从远处传来，打破了这死一般的寂静。
```

---

### 模式4：情绪映射

**结构**：环境特征 → 暗示角色情绪

**模板**：
```
[环境描述]，[暗示情绪的比喻/评价]。
```

**示例**：
```
天边的乌云越压越低，仿佛预示着即将到来的风暴。
李寒抬头看了一眼天空，嘴角勾起一丝冷笑——暴风雨，正合他意。
```

---

### 模式5：时间推移

**结构**：时间变化 + 环境变化

**模板**：
```
[时间指示词]，[对应的环境变化]。
```

**示例**：
```
不知过了多久，天边已经泛起了鱼肚白。
海面上的薄雾渐渐散去，远处的岛屿轮廓变得清晰起来。
```

### 环境描写素材库

#### 海洋场景
```
【平静海面】
海面像一块巨大的蓝色绸缎，在阳光下泛着粼粼波光。
偶尔有几只海鸥掠过水面，留下一串白色的涟漪。

【暴风雨】
狂风卷起巨浪，像一只只张牙舞爪的怪兽扑向船舷。
闪电撕裂了漆黑的天幕，照亮了船员们惊恐的脸。

【日出日落】
太阳从海平面缓缓升起，将天空和海面都染成了火红色。
海风带来清晨的凉意，混合着淡淡的盐味。
```

#### 城镇场景
```
【繁华街道】
街道两旁的摊贩高声叫卖，人群熙熙攘攘地穿行其中。
烤肉的香气混合着汗臭味，形成一种独特的"市井气息"。

【破败小巷】
阴暗的小巷里堆满了垃圾，散发着腐烂的气息。
几只野猫从废墟中窜出，消失在更深的黑暗里。

【酒馆】
酒馆里弥漫着酒精和烟草的气息，喧闹声几乎要掀翻屋顶。
角落里坐着几个形迹可疑的家伙，用警惕的眼神打量着每一个进来的人。
```

#### 战斗场景
```
【战斗前】
空气变得凝重起来，仿佛连风都停止了流动。
两人对峙着，杀气在彼此之间碰撞，发出无形的火花。

【战斗中】
地面被踩出一个个深坑，碎石飞溅得到处都是。
空气中弥漫着焦糊味，那是霸气爆发时留下的痕迹。

【战斗后】
硝烟渐渐散去，只剩下满地的狼藉和倒在地上的身影。
鲜血染红了土地，在阳光下散发着刺鼻的铁锈味。
```

## 动作描写模式

### 模式1：慢镜头特写

**结构**：动作分解 + 细节放大

**模板**：
```
[动作起始]。[关键动作放大]。[结果/反应]。
```

**示例**：
```
索隆的手握住了刀柄。
下一瞬，三道刀光同时闪过——快得肉眼几乎捕捉不到。
当刀光消失时，敌人才意识到自己的衣服已经被切成了碎片。
```

---

### 模式2：连续动作流

**结构**：动作1 + 动作2 + 动作3...（快节奏）

**模板**：
```
[动作]，[动作]，[动作]，[最终结果]。
```

**示例**：
```
李寒侧身闪过刀锋，反手一刀，跃起，旋转，刀光如银色的闪电划过——
敌人的武器被劈成两半，本人也被震退了三步。
```

---

### 模式3：动作+感受

**结构**：动作描述 + 身体感受/心理反应

**模板**：
```
[动作描述]，[身体感受/心理反应]。
```

**示例**：
```
李寒用力挥出这一刀，手臂上的肌肉绷得发疼，但胸中的战意却越来越盛。
这一刀包含了他全部的力量——如果这都无法击败对手，那就只能用命来拼了。
```

---

### 模式4：对比强化

**结构**：对手动作 vs 主角动作

**模板**：
```
[对手动作]。[主角的应对]。[结果对比]。
```

**示例**：
```
老鼠的匕首刺来，快如毒蛇吐信。
李寒却连眼皮都没抬，只是侧身一让，匕首从他耳边擦过，带起一缕发丝。
"就这？"他冷冷地说。
```

---

### 模式5：环境互动

**结构**：动作 + 环境反应

**模板**：
```
[动作描述]，[环境的反应/变化]。
```

**示例**：
```
索隆的刀气劈出，空气仿佛都被撕裂了。
刀气所过之处，地面被切开一道深深的沟壑，碎石飞溅得到处都是。
```

---

### 动作描写素材库

#### 攻击动作
```
【刀剑】
刀光如匹练般展开，带着凌厉的杀意。
剑身在空气中划出一道银色的弧线，直取对方咽喉。

【拳脚】
一拳轰出，拳风呼啸，带起一阵气浪。
旋踢的威力足以踢断一棵大树，更别说是人的骨头。

【远程】
子弹划破空气，发出尖锐的呼啸声。
弓弦一松，箭矢如流星般射向目标。
```

#### 防御动作
```
【格挡】
刀身横在身前，硬生生接下了这一击，双臂被震得发麻。
两柄武器相交，爆发出刺耳的金属碰撞声和四溅的火花。

【闪避】
身形一晃，险险避开了这致命的一击，刀锋从他脸颊边掠过。
他的身体向后仰去，攻击从他鼻尖前不到一寸的地方划过。

【后撤】
感受到危险的气息，他连退三步，拉开了与对手的距离。
脚下一蹬，整个人向后飞退，落地时在地上拖出两道深深的痕迹。
```

#### 日常动作
```
【走路】
他大步流星地走进来，每一步都带着不容置疑的气势。
她的脚步轻盈而优雅，仿佛一只蝴蝶在花丛中飞舞。

【坐下】
他重重地坐进椅子里，疲惫写在每一道皱纹上。
她端庄地坐下，腰背挺直，目不斜视。

【喝酒】
他一仰头，一杯烈酒入喉，辛辣的感觉让他舒服地眯起了眼睛。
她轻抿一口红酒，嘴角勾起一丝神秘的微笑。
```

## 心理描写模式

### 模式1：直接陈述

**结构**：直接描述角色的想法/情绪

**模板**：
```
[角色]心中[情绪/想法]。
```

**示例**：
```
李寒心中一凛，这个老鼠比想象中更难对付。
一股久违的兴奋在胸中燃烧，他已经很久没有遇到这样的对手了。
```

---

### 模式2：内心独白

**结构**：角色的直接思考（可用斜体或引号标注）

**模板**：
```
[内心想法]。[角色]如此想着，[外在动作/表情]。
```

**示例**：
```
不对劲。
李寒的眼睛微微眯起。这个老鼠，表面上唯唯诺诺，但他的站位...
是随时可以逃跑的方向。他在防备什么？
```

---

### 模式3：身体反应映射

**结构**：用身体反应暗示心理状态

**模板**：
```
[身体反应]，[暗示的情绪]。
```

**示例**：
```
他的心跳陡然加速，手心渗出了冷汗。
——危险。直觉在尖叫。
```

---

### 模式4：回忆闪回

**结构**：当前情况触发回忆

**模板**：
```
[当前场景]，[触发回忆的契机]。[回忆内容]。[回到现实]。
```

**示例**：
```
索隆的刀法让李寒想起了师父。
那个老头也是这样，明明每一刀都看似轻描淡写，却蕴含着恐怖的力量。
"专注！"师父的声音仿佛还在耳边回响。
李寒收回纷乱的思绪，重新聚焦于眼前的战斗。
```

---

### 模式5：矛盾心理

**结构**：两种想法的冲突

**模板**：
```
一部分的[角色]想要[想法A]，但理智告诉他[想法B]。
```

**示例**：
```
李寒很想现在就动手，一刀结果了这个阴险的老鼠。
但理智告诉他，现在还不是时候——他需要老鼠的情报，至少现在需要。
忍。他在心中对自己说。
```

---

### 心理描写素材库

#### 正面情绪
```
【兴奋】
血液仿佛都沸腾了起来，每一个细胞都在呐喊着"战斗"。
这种感觉...已经很久没有了。

【期待】
他的心跳不自觉地加快了几分，嘴角也忍不住微微上扬。
接下来会发生什么？他有些迫不及待地想要知道。

【满足】
一种深深的满足感涌上心头，所有的付出都值了。
他长舒了一口气，紧绑的神经终于放松下来。
```

#### 负面情绪
```
【愤怒】
怒火在胸中燃烧，几乎要冲破理智的束缚。
他的拳头握得咯咯作响，指甲几乎要刺进掌心。

【恐惧】
一股寒意从脊椎窜上后脑，全身的汗毛都竖了起来。
逃...快逃...这个念头不断在脑海中回响。

【绝望】
所有的希望都像肥皂泡一样破灭了，只剩下无尽的黑暗。
他的眼神变得空洞，仿佛失去了灵魂。
```

#### 复杂情绪
```
【矛盾】
他想相信，却不敢相信。
心中两个声音在不断争吵，让他头疼欲裂。

【释然】
所有的纠结和担忧都像潮水一样退去，只剩下平静。
原来，放下也可以是一种力量。

【苦涩】
嘴里满是苦涩的味道，他不知道该哭还是该笑。
原来，人生就是这样，得到的同时也在失去。
```

## 外貌描写模式

### 模式1：特征聚焦

**结构**：选取1-2个最突出的特征重点描写

**示例**：
```
最先映入眼帘的是他腰间的三把刀。
绿色的头发在阳光下闪着光，和他冷漠的眼神形成鲜明对比。
```

---

### 模式2：动态外貌

**结构**：在动作中展现外貌

**示例**：
```
他大步走进来，黑色的斗篷随着动作猎猎作响，露出里面闪着冷光的刀柄。
那张刀削般的脸上没有任何表情，只有一双眼睛像鹰一样锐利。
```

---

### 模式3：他人视角

**结构**：通过其他角色的观察描写

**示例**：
```
老鼠偷偷打量着眼前的年轻人。
普通的海军制服，普通的身材，普通的面孔——
但那双眼睛...老鼠的心跳漏了一拍。
那不是一个普通海军应该有的眼神。
```

## 氛围营造模式

### 紧张氛围

**关键词**：压抑、窒息、危险

**模板**：
```
空气[变化描述]，[静态描写]。[动态变化暗示危险]。
```

**示例**：
```
空气变得黏稠起来，仿佛连呼吸都要费力。
四周安静得可怕，只有两人的呼吸声清晰可闻。
李寒感觉到后背有一股视线——有人在暗中窥视。
```

---

### 战斗氛围

**关键词**：爆发、激烈、震撼

**示例**：
```
刀剑相交的瞬间，气浪向四周扩散，将地面的沙石都掀了起来。
两道身影在空中交错，快得只能看到残影。
每一次碰撞都爆发出刺耳的金属碰撞声，火花四溅。
```

---

### 诡异氛围

**关键词**：不安、神秘、诡异

**示例**：
```
月光从云层的缝隙中洒下，将小巷切割成明暗交替的碎片。
不知从哪里传来一阵低沉的笑声，却看不到任何人影。
墙上的影子似乎在动，但当李寒盯着看时，又什么都没有。
```

## 使用指南

### 选择合适的模式

| 场景类型 | 推荐模式 |
|---------|---------|
| 开场/过渡 | 环境模式1（全景到特写） |
| 战斗场景 | 动作模式1（慢镜头）+ 模式2（连续动作流） |
| 对峙场景 | 氛围模式（紧张）+ 心理模式3（身体反应映射） |
| 日常场景 | 环境模式2（感官叠加）+ 动作模式5（环境互动） |
| 情感场景 | 心理模式2（内心独白）+ 模式4（回忆闪回） |

### 组合使用原则

1. **不要机械套用**：模式只是参考，要根据具体情况灵活运用
2. **避免堆砌**：不是用得越多越好，适度即可
3. **保持一致**：同一场景的描写风格要统一
4. **服务剧情**：描写是为了增强叙事效果，不是炫技
