## 对话基础原则

### 三大核心原则

#### 1. 辨识度原则

**定义**：不看名字也能认出是谁在说话

**实现方式**：
- 独特的用词习惯
- 特定的语气特点
- 标志性的口头禅

**示例**：
```
✅ 辨识度高：
"切，就这点程度？"（索隆）
"肉！我要吃肉！"（路飞）
"小姐，请让我为您效劳。"（山治）

❌ 辨识度低：
"我们走吧。"
"好的。"
"那就这样办吧。"
（谁都可以说的话）
```

#### 2. 配合原则

**定义**：对话必须配合动作、神态、语气描写

**错误示例**：
```
❌ 纯对话（对话呆板）：
"你来干什么？"
"我来找你。"
"有什么事？"
"有件事想和你商量。"
```

**正确示例**：
```
✅ 配合动作神态：
"你来干什么？"老鼠眯起眼睛，手悄悄摸向腰间的匕首。
李寒不动声色地扫了一眼那只手，嘴角勾起一丝笑意："有件事想和你商量。"
"商量？"老鼠的眼中闪过一丝警惕，"你我之间，有什么好商量的？"
```

#### 3. 信息原则

**定义**：好的对话能推进剧情或揭示角色

**对话应该至少完成以下一项**：
- 推进情节（透露信息、做出决定）
- 揭示角色（展示性格、暴露动机）
- 建立关系（展示人物关系、变化）
- 制造冲突（产生矛盾、加剧紧张）

## 对话格式规范

### 基础格式

**标准结构**：
```
"对话内容。"[角色名][动作/神态/语气]。
```

**变体结构**：
```
[角色名][动作]，"对话内容。"
[角色名][动作]："对话内容。"
"对话内容，"[角色名][动作]，"后续内容。"
```

### 标点规范

**引号内标点**：
- 句号、问号、感叹号放在引号内
- 逗号在句子未完时使用

**示例**：
```
"你来干什么？"他冷冷地问。
"我..."她犹豫了一下，"我有件事想告诉你。"
"够了！"他一拍桌子，"我不想再听你解释！"
```

### 长对话处理

**原则**：避免大段独白，适时加入打断或反应

**示例**：
```
❌ 大段独白：
老鼠开始滔滔不绝地说起来："事情是这样的，三年前我在第77支部任职，
那时候我的上司是个贪婪的家伙，他逼我做了很多不想做的事情，后来
我终于找到机会调到了这里，本以为可以重新开始，没想到这里更糟糕..."
（太长了，读者会跳过）

✅ 适时打断：
"事情要从三年前说起。"老鼠叹了口气，"那时候我在第77支部..."
"说重点。"李寒打断了他。
老鼠的眼皮跳了跳，咽下了那些冗长的铺垫："简单来说，我知道蒙卡的秘密。"
```

## 潜台词技巧

### 什么是潜台词？

**定义**：话里有话，表面意思背后还有一层真实含义

### 潜台词类型

#### 1. 威胁型潜台词

**表面友好，暗藏威胁**

**示例**：
```
"李寒啊，"老鼠拍了拍他的肩膀，"你是个聪明人。聪明人，应该知道
什么该说，什么不该说。对吧？"

潜台词：你要是敢说出去，我就杀了你。
```

#### 2. 试探型潜台词

**看似随意，实则试探**

**示例**：
```
"最近谢尔兹镇挺热闹的。"老鼠漫不经心地说，"听说有个新来的士兵
挺能干的。你认识吗？"

潜台词：我在调查你，你最好老实交代。
```

#### 3. 暗示型潜台词

**不直说，让对方自己领会**

**示例**：
```
"准将大人很欣赏你。"李寒看着老鼠的眼睛，"但是，他更在乎海军的名誉。"

潜台词：你要是继续贪污，我就举报你，准将会站在我这边。
```

#### 4. 反讽型潜台词

**说的是赞美，实际是讽刺**

**示例**：
```
"老鼠上校真是好手段啊。"索隆冷笑一声，"连海贼都能合作，佩服佩服。"

潜台词：你这个叛徒，迟早会被清算。
```

### 潜台词写作技巧

1. **对比反差**：表面的话与实际意图形成反差
2. **关键词暗示**：用特定词汇暗示真实意图
3. **语气提示**：通过动作神态暗示潜台词
4. **上下文铺垫**：读者能从前文理解潜台词

## 对话节奏控制

### 节奏类型

| 节奏类型 | 特点 | 适用场景 |
|---------|------|---------|
| 快节奏 | 对话简短、紧凑、动作频繁 | 紧张、战斗、争吵 |
| 中节奏 | 对话适中、有停顿、有描写 | 日常、讨论、交流 |
| 慢节奏 | 对话细腻、大量描写、内心戏 | 情感、回忆、沉思 |

### 快节奏对话

**特点**：
- 对话简短有力
- 减少描写，增加张力
- 动作密集

**示例**：
```
"让开。"
"不让。"
"找死？"
索隆的手已经握住了刀柄。
"你动手试试。"李寒的声音冰冷。
空气仿佛凝固了。
```

### 中节奏对话

**特点**：
- 对话有来有往
- 配合适量描写
- 节奏自然

**示例**：
```
"你想要什么？"李寒靠在椅背上，手指轻轻敲击着桌面。
老鼠的眼珠转了转："合作。"
"合作？"李寒挑了挑眉，"有意思。"
"你帮我除掉蒙卡，"老鼠压低了声音，"我给你情报。"
李寒没有说话，只是用一种让人不寒而栗的目光盯着老鼠。
沉默持续了大约十秒。
"...还有钱。"老鼠补充道，额头上渗出了汗珠。
```

### 慢节奏对话

**特点**：
- 对话细腻深入
- 大量心理描写
- 情感充沛

**示例**：
```
"你为什么要帮我？"
娜美的声音很轻，轻得几乎听不见。她低着头，不敢看李寒的眼睛。

李寒没有立刻回答。他看着眼前这个女孩——坚强的外表下，藏着一颗
已经伤痕累累的心。

"因为..."他顿了顿，"因为你值得被帮助。"

娜美的身体微微颤抖了一下。她抬起头，眼眶已经红了。

"你不了解我。"她的声音有些沙哑，"你不知道我做过什么..."

"我不在乎。"李寒打断了她，声音平静而坚定，"我只在乎你想做什么。"
```

### 节奏转换

**技巧**：在关键节点转换节奏，制造张力

**示例**：
```
【中节奏铺垫】
"所以，你的意思是..."李寒若有所思地说。
"没错。"老鼠得意地笑了，"只要你帮我，我们就能..."

【突然转快】
"够了。"
李寒的声音突然变冷。
老鼠的话卡在了喉咙里。
"我不和叛徒合作。"
刀已经架在了老鼠的脖子上。
```

## 对话类型与模板

### 类型1：信息交换型

**目的**：传递重要信息

**模板**：
```
A提问/引入话题 → B回答/透露信息 → A追问/确认 → B补充/解释
```

**示例**：
```
"老鼠最近有什么动静？"李寒问。
"他在秘密联系阿龙。"情报员压低声音，"好像在谈什么交易。"
"什么交易？"
"不清楚。但是..."情报员凑近了些，"我听到他们提到了'航海图'。"
```

### 类型2：冲突对抗型

**目的**：展示矛盾，制造紧张

**模板**：
```
A立场表达 → B反驳/质疑 → A坚持/升级 → B反击 → 冲突爆发或暂时平息
```

**示例**：
```
"把钱交出来。"蒙卡冷冷地说。
"这是村民们的血汗钱。"娜美咬着牙，"我不会给你。"
"你以为你有选择吗？"蒙卡大步走近。
"我宁可死！"娜美后退一步，但没有退缩的意思。
蒙卡停下了脚步，眼中闪过一丝意外——然后是更深的恶意。
```

### 类型3：协商谈判型

**目的**：达成协议或交易

**模板**：
```
A提出条件 → B讨价还价 → A让步或坚持 → B妥协或反提条件 → 达成一致或破裂
```

**示例**：
```
"我要三成。"李寒伸出三根手指。
"太多了。"老鼠摇头，"一成，最多一成。"
"那就没什么好谈的了。"李寒站起身，作势要走。
"等等！"老鼠叫住他，"...两成，两成可以。"
李寒转过身，嘴角带着胜利者的微笑："成交。"
```

### 类型4：情感交流型

**目的**：展示角色情感，加深关系

**模板**：
```
A打开心扉 → B回应/倾听 → 情感共鸣 → 关系升华
```

**示例**：
```
"我很害怕。"索隆的声音很低，"不是害怕失败..."
李寒没有说话，只是安静地听着。
"我害怕的是..."索隆抬头看向天空，"死在成为世界第一剑豪之前。"
"你不会的。"李寒说，声音平静而坚定。
索隆转头看向他。
"因为你不是那种会死的人。"李寒的嘴角微微上扬，"你是那种会让敌人先死的人。"
索隆愣了一下，然后笑了——那是李寒第一次看到他笑。
```

### 类型5：幽默调侃型

**目的**：缓和气氛，展示角色关系

**模板**：
```
A抛出话题 → B吐槽/调侃 → A反击 → 相互打趣
```

**示例**：
```
"那边有个漂亮的小姐..."山治眼冒心形。
"你能不能正常一点？"索隆翻了个白眼。
"你懂什么！"山治瞪着他，"你这个只知道举铁的肌肉笨蛋！"
"比你这个整天发花痴的变态强。"
"你说什么？！"
两人差点又打起来。
乌索普在一旁叹气："每天都这样，真是够了..."
```

## 质量检查清单

### 辨识度检查

- [ ] 每个角色的说话方式有独特性
- [ ] 不看名字能猜出是谁在说话
- [ ] 口头禅和用词习惯一致

### 格式检查

- [ ] 对话配有动作/神态/语气描写
- [ ] 标点符号使用正确
- [ ] 避免大段独白

### 功能检查

- [ ] 对话推进了情节或揭示了角色
- [ ] 对话有信息量，不是废话
- [ ] 对话节奏与场景氛围匹配

### 潜台词检查

- [ ] 重要对话有潜台词
- [ ] 潜台词能被读者理解
- [ ] 潜台词与角色性格一致

### OOC检查

- [ ] 对话符合角色性格
- [ ] 用词符合角色设定
- [ ] 语气符合场景需要
