# 阶段2：引擎设计

## 目标
设计让读者看完第1章就停不下来的"创意引擎"——贯穿全书的核心矛盾。输出至少3个完全不同的方案供用户选择。

## 前置读取
- `recall("decision")` → 获取类型、吸引力、用户设定

## 引擎维度库

以下8个维度代表不同的"读者追看动力"。生成方案时从中选3个**最匹配用户设定**的维度，每个方案用不同维度。

| 维度 | 核心吸引力 | 读者爽感来源 | 参考模式 |
|------|----------|------------|---------|
| 🔴 **生死倒计时** | 明确致命威胁+具体deadline推进，主角在倒计时内破局 | "他能活过这一章吗？" | 穿越成注定被杀的角色，或被卷入有明确时限的致命阴谋 |
| 🟡 **道德两难** | 两个都想保护但必须二选一，每条路都有沉重不可逆代价 | "他会怎么选？选完怎么面对？" | 救恩人还是救任务目标、忠于组织还是忠于良心 |
| 🔵 **身份秘密** | 伪装身份的每次互动都是刀尖行走，暴露=毁灭 | "这层皮还能撑多久？" | 卧底在敌方核心，或穿越者必须隐藏真实来历 |
| 🟣 **幕后操盘** | 多身份/多暗线运作，读者全知但角色被蒙蔽，戏剧反讽 | "他在下一盘大棋，所有人被蒙在鼓里" | 《转生眼中的火影世界》：多重身份暗中影响局势，被派去调查的对象恰好是自己 |
| 🟤 **反差演绎** | 内心与外在、或真实能力与表面身份存在巨大落差 | "所有人都误解了他，只有读者知道真相" | 《我，东海山贼王》：影帝系统扮演KING，内心恐惧但外在嚣张——"像你这样的四皇我已经干掉56个" |
| 🟠 **知识降维** | 利用高维知识（未来信息/跨界科技/游戏机制）碾压当前世界认知盲区 | "卧槽还能这样用？" | 《这个海军不正经》：用现代物理学开发极光果实，实现闪闪果实+响雷果实的复合能力 |
| ⚪ **社交博弈** | 人际关系网络=权力=成长，每结交一人就打开一条路 | "又收服了一个关键人物" | 《三国：坏了，我成汉末魅魔了》：羁绊系统将社交关系直接转化为属性成长，用诗文书法把群雄"社交绑定" |
| 🔷 **体系建设** | 从零搭建体系，长线投入在关键节点集中爆发 | "种田50章的积累在一场大战中全部兑现" | 《神话版三国》：纯文臣内政种田路线，用经济制度体系碾压拥有神话武力的武将 |

**维度选择规则**：
1. 先看用户的★核心设定，识别最匹配的2-3个维度
2. 3个方案必须用**不同的维度组合**——不是选1个维度，每个方案可以有1个主维度+1个辅维度
3. 如果用户设定天然是"权谋上位"类，不要硬拉到"道德两难"——而是在权谋框架内用不同维度切入（如：方案A=🟣操盘+🔷建设，方案B=🟤反差+⚪社交，方案C=🔴生死+🟠知识）

## 流程

> 输出选项时遵循「交互输出规则」：每项一行、≤25字、末尾提示"回复字母即可"

### 0. 设定梳理
从用户输入中梳理设定，展示给用户确认：
- ★ 核心设定（用户反复强调）→ 必须融入
- ☆ 偏好设定（提过但没强调）→ 尽量融入，可调整
- ○ 开放设定（未指定）→ 由创意决定

如果好创意与☆偏好冲突，和用户讨论取舍，不为覆盖设定牺牲创意。

### 1. 创意发散（反套路→被忽略的宝藏→维度匹配）

先忘掉设定清单。按以下步骤严格执行：

**第一步：反套路排雷**
这个世界观的同人文/穿越文最常见的3个开局套路是什么？逐一列出，然后**全部排除**——不许用这些作为方案的**核心引擎**。
（例：海贼王常见套路 → ①觉醒隐藏果实无脑变强 ②穿越成原作角色改命 ③开局就挑战四皇。全部禁止作为核心引擎。）
注意：排除的是"引擎骨架"而非"具体设定"。比如"从底层往上爬"不是套路，"靠系统数值碾压往上爬"才是。

**第二步：挖掘被忽略的宝藏**
从世界观知识库中找：
- 3个**被大多数作者忽略**的角色、地点或设定
- 每个写一句：为什么它其实有**巨大的戏剧潜力**？
（例：海贼王中费舍尔·泰格——徒手爬上红土大陆解放奴隶，临死却拒绝人类输血。他的太阳海贼团旧部至今散落各地。）

**第三步：5个画面自由发散**
暂时不考虑任何设定限制，用世界观的具体细节生成**5个画面**：
- 每个画面30字内，只有「人物+动作+紧张感」
- 必须用到世界观中的**具体名词**（人名、地名、组织名、能力名），不许用泛称
- 画面之间尽量覆盖不同的场景类型（战斗、谈判、逃亡、暗杀、审判、背叛……）

**第四步：维度匹配**
根据用户的★核心设定，从维度库中选出3个最匹配的维度。然后从5个画面中，为每个维度各挑1个最契合的画面作为方案起点。

如有画面能自然承载★核心设定则优先。如有冲突，以创意优先、与用户讨论取舍。

### 2. 展开方案
每个方案格式：

```
方案X：「标题」（主维度：🟣/🔴/🟤...）

★ 卧槽画面（30字内，纯场景）：
  "[人物+动作+紧张感]"

故事前提：2-3句话说清核心矛盾

主角的困境：
  为什么不能不管？→ [世界观里的具体原因]
  冲突从哪来？→ [什么人/势力在推动]
  解决了会怎样？→ [成功，但自然引发更大的问题]

开局3章：
  第1章：[一个具体场景]
  第2章：[一个具体场景]
  第3章：[一个具体场景]

弧线预览（3-5弧）：
  弧1 → 弧2 → 弧3

设定融入：★ ... ☆ ...
```

### 3. 用户选择
展示方案，用户选择、修改或组合。确定后写入 engine.md。

## 质量标准

以下是不同维度的合格示例。生成时参考**质量水平和维度差异**，不要照搬内容。

### 示例A 🔴 生死倒计时型（水浒世界观，穿越类）

**方案：「水浒：武大郎的反杀」**

★ 卧槽画面：
"潘金莲端着一碗汤走过来，笑容温柔得可怕。你知道那碗汤里有砒霜。她已经走到桌前了。"

故事前提：穿越成武大郎，知道原剧情中自己会被潘金莲和西门庆合谋毒死。身体矮小虚弱，没有武力没有势力，倒计时已经开始——王婆已经在搭线了。

主角的困境：
- 为什么不能不管？→ 不行动就按原剧情被毒死，这不是选择题
- 冲突从哪来？→ 潘金莲和西门庆的阴谋在推进，王婆在穿针引线，县令收了西门庆的钱——整个阳谷县的权力结构都站在对面
- 解决了会怎样？→ 躲过毒杀，但暴露了"武大郎变聪明了"。西门庆不会善罢甘休——一个卖炊饼的敢坏他好事？他会动用县令的力量来碾压你

开局3章：
- 第1章：潘金莲端汤，你假装虚弱喝下但偷偷吐掉，开始装病拖延时间
- 第2章：装病期间偷听到王婆和潘金莲在隔壁密谋第二次下毒的时间——就在三天后武松回信说不回来的那天
- 第3章：你趁"病重"无人防备，悄悄找到郓哥帮忙送信给武松。但信还没送出，你在街上看到了西门庆——他正带着县令的师爷朝你家走来

**为什么有效**：每一章都有具体的致命威胁推着剧情走，读者不敢停。

### 示例B 🟣 幕后操盘型（火影世界观，穿越类）

**方案：「火影：调查我自己的暗部」**

★ 卧槽画面：
"带土把一份任务卷宗拍在你桌上：'查出"阎罗"的真实身份。'你面无表情接过——"阎罗"就是你的另一个身份。"

故事前提：穿越成日向分家成员，为摆脱笼中鸟封印，暗中与大蛇丸合作研究血继进化。白天是木叶忠诚忍者，夜晚以"阎罗"身份运营地下情报网。当暗部开始调查"阎罗"时，任务落到了你头上。

主角的困境：
- 为什么不能不管？→ 笼中鸟封印随时能杀死你，唯一出路是进化转生眼
- 冲突从哪来？→ 你的两个身份开始互相追猎。止水怀疑"阎罗"和你有关，鼬在暗中观察你的反应
- 解决了会怎样？→ 成功洗清嫌疑，但止水和鼬变成了你最亲密的战友——他们不知道自己信任的人正是他们追了三年的目标

开局3章：
- 第1章：作为木叶忍者执行任务时，你故意留下"阎罗"的假线索引向云隐——嫁祸给对手村
- 第2章：止水主动找你搭档调查，你发现他的瞳术能看穿变化术——你的伪装第一次出现裂缝
- 第3章：大蛇丸的实验基地被暗部发现，你必须在"阎罗"的身份暴露前销毁所有证据——但鼬已经在基地里等着了

**为什么有效**：读者全知，角色全蒙。"调查自己"的戏剧反讽让每一次对话都充满潜台词。

### 示例C 🔷 体系建设 + ⚪ 社交博弈型（三国世界观，穿越类）

**方案：「神话三国：文臣的种田碾压」**

★ 卧槽画面：
"吕布一枪凿穿三千人的军阵，碎石飞溅到你脸上。你擦掉血，低头看着手里的农业改良方案——这才是真正能赢他的东西。"

故事前提：穿越到武将能单骑破万的神话三国，你是刘备帐下文臣，没有武力，没有天赋。但你有超越时代2000年的内政知识——每一次改良农具、优化税制、建立后勤体系，都在为下一场战争积累碾压优势。

主角的困境：
- 为什么不能不管？→ 刘备的地盘最小最穷，不种田就会被曹操碾平
- 冲突从哪来？→ 武将们看不起文臣，觉得"打仗靠拳头"。你的内政改革触动了世家大族的利益
- 解决了会怎样？→ 经济碾压让刘备势力暴涨，但引来曹操和袁绍的联手绞杀——你的种田速度能赶上他们的军事压力吗？

开局3章：
- 第1章：你在军议上提出"屯田制"被张飞嘲笑"书生误国"。关羽沉默不语。刘备说"试试"
- 第2章：第一季粮食丰收，军粮翻倍。张飞在你面前啃着新麦饼，嘴硬说"还行吧"——你知道他服了
- 第3章：曹操的密探把你的屯田方案偷回了许昌。荀彧看完后对曹操说："这个人，要么收要么杀。"

**为什么有效**：种田回报的延迟满足感——花50章建设的成果在一场大战中爆发，读者等待的过程本身就是爽感。

### 示例D 🟤 反差演绎 + 🟣 幕后操盘型（海贼王世界观，穿越类）

**方案：「海贼王：老鼠部队的三等兵」**

★ 卧槽画面：
"老鼠上校拍着你的肩说'小李啊，这次和蒙卡的联合演习就靠你协调了'。你低头敬礼，心里默数——还有47天，路飞就会打到这里。"

故事前提：穿越成老鼠部队的底层三等兵。你知道原作剧情：路飞会打败老鼠，阿龙会被清算。你的计划是在这47天里，借老鼠的信任挑起他和蒙卡的矛盾，让两败俱伤，你来收拾残局。但你是个前世懦弱的肥宅——每次要开口算计别人，手都在抖。

主角的困境：
- 为什么不能不管？→ 路飞来了之后老鼠部队全军覆没，你如果还是三等兵就是炮灰
- 冲突从哪来？→ 老鼠贪婪多疑但不蠢，蒙卡暴虐但有真实武力，你要在两个上校之间玩火
- 解决了会怎样？→ 老鼠倒台你接管残局，但引起了海军本部的注意——一个三等兵怎么在两个上校的互斗中毫发无伤？

开局3章：
- 第1章：你利用先知信息"预判"了阿龙使者的到来时间，老鼠惊讶你的"情报能力"，破格提拔你当传令兵
- 第2章：你借传令兵身份接触蒙卡的部下贝鲁梅伯，发现这个富二代对父亲的暴政深恶痛绝——这是一个可以利用的裂缝
- 第3章：你在老鼠面前"无意"透露蒙卡在私扣海贼赏金（其实是你伪造的账本）。老鼠的眼睛亮了——这是他扳倒竞争对手的把柄

**为什么有效**：表面是唯唯诺诺的三等兵，内心是下棋的操盘手。读者看着一个"手在抖"的前肥宅精准操控两个上校互斗，反差产生的爽感和紧张感并存。

## 3条底线

1. **卧槽画面只有人物+动作+紧张感**——出现"系统提示""能量+""N%"等系统界面/数值即不合格
2. **冲突来自世界观内的人和势力**——不是金手指系统的内部规则（"能量枯竭""系统平衡者""正义值下降"都是系统惩罚，不合格）
3. **3个方案的起点场景完全不同**——不是同一骨架换外衣，NPC反应基于他们能观察到的行为（他们不知道穿越和系统的存在）

## 差异化标准（3条正面要求）

4. **3个方案的主维度必须不同**——从维度库8个维度中选3个不同的。如果3个都是同一种"权谋上位"路径，不合格
5. **每个方案的开局场景中，主角面对的第一个人不能相同**——迫使每个方案从不同的人物关系切入
6. **卧槽画面必须包含世界观中的具体名词**（人名/地名/组织名）——不能用"某个强者""一座城市"等泛称
