# 大纲结构规范精要

## 卷概述必需字段

- **核心主题**：本卷探讨的核心议题
- **核心冲突**：主角面临的主要矛盾
- **主角目标**：具体、可衡量的目标
- **角色弧光**：主角从什么到什么的内在转变
- **灵魂黑夜**：主角最低谷时刻（具体描述）
- **本卷收获**：力量、势力、盟友、内在成长
- **起承转合节点**：起(20%)→承(40%)→转(25%)→合(15%)

## 章节概述必需字段

- **章节概述**：1-3句话核心内容
- **章节节奏**：蓄势章/爆发章/释放章/过渡章
- **核心张力**：主角面临什么困境或抉择？（章节灵魂）
- **情节点**：3-7个，格式 `【小标题】具体描述(50-200字)`
- **情感曲线**：低谷/上升/高峰/下降 + 具体情绪
- **三层冲突**：内在(vs自己) / 人际(vs他人) / 外在(vs世界)
- **悬念**：引发好奇的问题
- **伏笔**：为后续埋下的线索(0-2个)

## 抑扬节奏规则

- 黄金比例：抑:扬 ≈ 4:6
- 禁止连续3章以上"释放章"
- 禁止连续5章以上"蓄势章"
- 高潮前必有蓄势，高潮后必有沉淀
- 每章至少一层冲突在推进

## 情节点质量要求

- **具体化**：❌"获得势力" → ✅ 描述收服谁、如何收服
- **有细节**：❌"与索隆战斗" → ✅ 描述招式、过程、结果
- **有因果**：前一个情节点为后一个铺垫
- **有代价**：成功要有代价，选择要有牺牲

## 伏笔规范

- 每卷埋设3-5个，回收2-3个
- 埋设自然（融入情节），回收合理（恍然大悟）
- 间隔3-10章为宜，长线伏笔(跨卷)不超过2个

## 引擎驱动检查

- **每章冲突必须来自引擎**，不是随机事件
- **弧线结尾必须导向下一弧**：解决A产生B
- **删掉任何一章，引擎链条应该会断**：每章都有存在意义
- **引擎升级时机**：当冲突开始重复时，扩大影响范围或引入新维度

### 引擎健康检查（每批完成后）

```
"最近5章的冲突还来自引擎吗？"
→ 是 → 引擎运转正常，继续
→ 否 → 引擎空转了，引入引擎升级事件
```

## 画面流要求

- 每章大纲必须包含**核心画面**（30字内具体场景）
- 画面中有人物、有动作、有紧张感
- 禁止用抽象机制替代画面描述

## 快速检查清单

- [ ] 起承转合完整？有灵魂黑夜？
- [ ] 抑扬比例合理？无连续同类型章节？
- [ ] 情节点具体(50-200字)？无模糊表述？
- [ ] 三层冲突每章至少推进一层？
- [ ] 角色行为符合性格/原作设定？
- [ ] 因果链完整？成功有代价？
- [ ] 每章冲突可回溯到引擎？
- [ ] 每章有具体画面（非机制说明）？
