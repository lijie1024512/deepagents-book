# 阶段4：大纲规划

## 目标
基于引擎和角色，规划弧线和章节大纲。5-10章一批滚动推进，每章冲突必须来自引擎。

## 前置读取
- 读取 `engine.md` → 引擎设计
- `recall("decision")` → 角色设定、用户决策
- 续写时：读最近2-3章正文 + `progress.md`

## 流程

### 1. 弧线规划（5-10章一批）

每个弧线：
```
弧线X：篇名（第N-M章）
  引擎状态：[低速/中速/高速/过载]
  核心冲突：[来自引擎的冲突]
  起(20%) → 承(40%) → 转(25%) → 合(15%)
  弧线终点→下弧起点：[解决A如何自然产生B]
```

### 2. 章节大纲（每章必须有核心画面）

```
第N章：「章名」
  核心画面："[30字内，人物+动作+紧张感]"
  核心张力：[本章冲突，来自引擎]
  三层冲突：外在/人际/内在 各推进了什么
  章末钩子：[读者为什么要翻下一页]
```

❌ "主角获得新能力，暴露风险增加"
✅ "罗的部下出现在同一座岛的酒馆里，主角的果实刚好在他面前失控了一秒"

### 3. 生成3个弧线方案供选择
```
方案A：保守型（引擎低速，积蓄力量）
方案B：平衡型（引擎中速，冲突与成长并行）
方案C：激进型（引擎高速，密集冲突快速升级）
```

### 4. 渐进式细化
用户选方案后：弧线概述→章节概述→详细情节点→辅助元素（钩子、伏笔、情感曲线）

### 5. 引擎健康检查（每批完成后）
"最近5章的冲突还来自引擎吗？" 否→引入引擎升级事件（扩大范围或新维度）

## 质量标准

以下是一个合格弧线的完整示例。参考**质量水平**，不要照搬内容。

### 示例（水浒世界观，武大郎引擎）

```
弧线1：毒杀倒计时（第1-5章）
  引擎状态：低速——潘金莲和西门庆的阴谋刚开始
  核心冲突：知道自己会被毒死，但身体虚弱无力反抗

  第1章：「那碗汤」
    核心画面："潘金莲端汤走来，笑容温柔得可怕，你知道那是砒霜"
    核心张力：喝还是不喝？不喝就暴露你知道真相
    三层冲突：
      外在：毒杀倒计时启动
      人际：潘金莲在观察你的反应
      内在：穿越者的现代道德vs求生本能
    章末钩子：你假装喝下毒汤又偷偷吐掉，但转身时——潘金莲正盯着你的嘴角

  第2章：「隔墙有耳」
    核心画面："你贴着墙听到王婆说：三天后武松回信说不回来，那天动手"
    核心张力：知道了死期但无法逃跑（逃跑=抛弃武大郎身份=失去一切）
    三层冲突：
      外在：倒计时3天
      人际：王婆在监视你的一举一动
      内在：该找武松还是自己解决？找武松=按原剧情走=自己还是死
    章末钩子：你偷偷出门找郓哥，但街角站着西门庆的家仆

  ...（第3-5章略）

  弧线终点→弧2起点：
  躲过毒杀 → 暴露"武大郎变聪明了" → 西门庆加码动用官府
```

**为什么这个弧线有效**：
- 每章冲突都来自引擎（毒杀阴谋），不是随机事件
- 每章核心画面有具体人物和动作，不是抽象描述
- 弧线终点自然产生下一弧（解决A产生B）
- 三层冲突都在推进

## 完成标志
- 至少一批（5-10章）大纲已确认并保存
