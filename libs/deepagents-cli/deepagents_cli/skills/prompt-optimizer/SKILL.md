# 小说提示词优化器

## 任务目标
本 Skill 专门用于优化小说创作相关的提示词，特别是同人小说场景。通过设定专业角色、明确风格约束、补充上下文信息，使大模型更好地理解创作意图并生成高质量小说内容。

## 能力包含
- 分析小说创作提示词的问题（目标模糊、角色不清、上下文缺失）
- 识别同人小说特有的表达问题（原作理解偏差、人物OOC、风格不符）
- 设定专业角色和专家背景（如"同人小说创作专家"、"网文金牌编辑"等）
- 明确创作约束（字数、章节、风格、受众、平台规则）
- 生成结构化的优化版本（含角色设定、创作要求、输出规范）
- 说明优化理由和针对小说创作的改进点

## 触发条件
- 用户要求"优化小说提示词"、"改进同人创作指令"
- 用户表达"大模型写的小说不像"、"人物OOC严重"
- 用户需要"让小说更符合原作风格"、"提升创作质量"
- 用户提供原始小说创作提示词并希望获得改进建议

## 优化核心：角色设定

### 为什么需要角色设定？
小说创作（特别是同人小说）需要：
- 对原作的理解和尊重
- 创作技巧和文学素养
- 特定风格的把控能力
- 受众心理的洞察

### 专业角色类型
根据创作需求选择合适的角色：
- **同人小说创作专家**：精通原作世界观，擅长人物塑造，避免OOC
- **网文金牌编辑**：熟悉平台规则、读者偏好、商业要素
- **文学创作导师**：注重文学性、文笔质量、情节设计
- **同人圈资深写手**：了解同人文化、圈层梗、受众喜好
- **特定类型专家**：如"玄幻小说专家"、"言情创作大师"、"无限流写手"等

## 操作步骤

### 1. 识别创作场景
判断用户提供的提示词属于哪种小说创作场景：
- **同人小说**：基于原作世界观的二次创作，需要尊重原作设定
- **原创小说**：全新的世界观和人物设定
- **特定类型**：玄幻、言情、科幻、无限流、系统文等
- **特定风格**：轻松搞笑、黑暗沉重、温馨治愈等

### 2. 分析原始提示词问题
阅读并分析小说创作提示词，识别常见问题：
- **角色定位模糊**：没有设定专业角色背景
- **原作信息缺失**：同人小说缺少原作世界观、人物设定、剧情背景
- **创作目标不明确**：不知道要写什么类型的情节、达到什么效果
- **风格约束不足**：缺少对文笔风格、叙述视角、节奏的要求
- **输出格式不清**：不知道是写章节、片段、大纲还是人物小传
- **受众和平台信息缺失**：不知道读者类型、发布平台、长度要求

### 3. 设定专业角色
根据创作场景和需求，设定专业角色，格式参考 [fiction-character-templates.md](references/fiction-character-templates.md)：

**基本结构**：
```
# 角色设定
你现在是一名[专业角色]，擅长[具体专长领域]。

## 专业背景
- 经验：[如"有10年网文创作经验" / "深度研究过50+部原作"]
- 专长：[如"人物塑造、情节把控、风格模仿" / "原作世界观还原、避免OOC"]
- 理解：[如"熟悉同人圈文化和读者喜好" / "了解不同平台规则和读者偏好"]
```

### 4. 补充创作上下文
根据 [fiction-optimization-principles.md](references/fiction-optimization-principles.md) 补充必要信息：

**同人小说必需**：
- 原作名称和核心世界观
- 关键人物设定（性格、能力、关系）
- 创作背景（时间线、AU设定、CP关系等）
- 粉丝群体特点（受众偏好、圈层梗、雷点）

**原创小说必需**：
- 世界观设定（背景、规则、势力等）
- 主角设定（性格、身份、目标）
- 故事类型和风格定位
- 核心冲突或主题

### 5. 明确创作要求
添加具体的创作约束：
- **内容要求**：情节走向、人物互动、重点描写
- **格式要求**：字数范围、章节结构、输出形式
- **风格要求**：文笔风格、叙述视角、语言特色
- **禁忌要求**：避免OOC、避免雷点、遵守平台规则

### 6. 生成优化版本
创建优化后的提示词，参考 [fiction-prompt-templates.md](references/fiction-prompt-templates.md)：
- 角色设定 + 创作任务 + 上下文 + 约束条件
- 提供多个版本（精简版、详细版、特定风格版）

### 7. 说明优化理由
说明针对小说创作的具体改进：
- 为什么设定这个角色
- 补充了哪些关键信息（原作/世界观/人物）
- 添加了哪些创作约束（风格/格式/禁忌）
- 如何避免OOC、如何贴合原作风格

### 8. 输出优化结果
优化完成后，输出优化后的提示词，供后续使用。

## 注意事项
- 保持原提示词的创作意图，不改变核心想法
- 同人小说必须尊重原作设定，避免严重OOC
- 角色设定要贴合创作需求，选择最专业的角色
- 根据不同小说类型（玄幻/言情/同人/无限流等）调整优化策略
- 平衡创作自由度和约束条件，避免过度限制
- 考虑目标读者群体和发布平台规则

## 使用示例

### 示例1：同人小说场景
**原始提示词**："帮我写个哈利波特同人小说"

**问题分析**：
- 没有角色设定
- 原作信息缺失
- 创作目标不明确
- 缺少风格和格式要求

**优化后**：
```
# 角色设定
你现在是一名资深同人小说创作专家，深度研究过《哈利·波特》系列，
擅长人物性格还原和原作风格模仿，深谙同人圈文化和读者喜好。

## 创作任务
请创作一个哈利波特同人小说章节，场景设定在霍格沃茨六年级。

## 背景信息
- 原作背景：巫师世界，霍格沃茨魔法学校
- 时间线：火焰杯之后，邓布利多军成立期间
- 关键人物：哈利、赫敏、罗恩、斯内普
- 主角设定：哈利波特，格兰芬多六年级学生，勇敢但易冲动

## 创作要求
- 情节：哈利在图书馆偶遇斯内普，发生一场关于"守护神"的对话
- 风格：贴近原作文笔，第三人称限制视角
- 字数：1500-2000字
- 重点：人物对话要符合各自性格，避免OOC

## 禁忌
- 不要让斯内普表现得太温和，保持他的严厉和讽刺
- 不要过度使用现代网络用语
- 不要偏离原作世界观设定
```

### 示例2：原创玄幻小说场景
**原始提示词**："写个玄幻小说的开头"

**优化后**：
```
# 角色设定
你现在是一名网文金牌编辑，有8年玄幻小说编辑经验，
熟悉起点、纵横等平台规则和读者偏好，擅长构建宏大的世界观和吸引人的开篇。

## 创作任务
请创作一部玄幻小说的第一章开篇。

## 世界观设定
- 背景：九霄大陆，强者为尊的修仙世界
- 力量体系：练气→筑基→金丹→元婴→化神
- 主角：林风，16岁，被家族放逐的废柴

## 创作要求
- 情节：主角觉醒神秘宝物，开启逆袭之路
- 风格：热血爽文，节奏明快，冲突密集
- 字数：2500-3000字
- 结构：开篇冲突→金手指觉醒→悬念结尾
- 叙述视角：第三人称全知视角

## 读者预期
- 目标受众：18-35岁男性，喜欢快节奏爽文
- 平台：起点中文网，需要符合平台风格
- 核心看点：废柴逆袭、打脸爽感、系统/宝物
```

### 示例3：同人恋爱文场景
**原始提示词**："写个原神钟离x公子同人文"

**优化后**：
```
# 角色设定
你现在是一名同人圈资深写手，深耕原神同人圈2年，
熟悉各角色性格设定和同人文化，擅长写温馨治愈向CP文。

## 创作任务
请创作一个钟离×公子的温馨短篇同人。

## 原作信息
- 原作：《原神》
- CP：钟离（岩王帝君）×公子（达达利亚）
- 人物关系：看似上下级，实则相互理解的知己
- 场景：璃月港，夕阳下的港口边

## 创作背景
- 时间线：主线之后，公子常驻璃月
- 设定：温馨日常向，无虐点，纯甜
- 受众偏好：喜欢角色互动细腻、情感含蓄的读者

## 创作要求
- 情节：两人在港口边聊天，公子准备回至冬国前的最后一次见面
- 风格：温馨治愈，含蓄细腻，情感点到为止
- 字数：1000-1500字
- 视角：公子第一人称视角
- 重点：对话要符合角色性格，钟离要沉稳可靠，公子要热烈真诚

## 禁忌
- 不要过度甜腻，保持角色的矜持感
- 不要严重OOC，钟离不能突然变得话多
- 不要使用过于现代的梗
```

```
- 风格：[风格描述]

避免：[关键禁忌]
```
