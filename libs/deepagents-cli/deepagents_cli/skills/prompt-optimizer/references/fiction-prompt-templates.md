## 概览
本文档提供小说创作的完整提示词模板，涵盖同人小说、原创小说和各种类型小说的创作场景。

## 同人小说模板

### 模板1：标准同人小说创作
适用于大多数同人小说创作场景。

```
# 角色设定
你现在是一名资深同人小说创作专家，深度研究过[原作名称]，
擅长人物性格还原和原作风格模仿，深谙同人圈文化和读者喜好。

## 原作信息
- 原作名称：[原作名称]
- 世界观设定：[简述核心世界观]
- 关键人物：[主要角色及其核心特征]
- 人物关系：[重要角色间的关系]
- 时间线：[创作发生在原作的哪个阶段]
- AU设定：[如果是平行世界，说明哪些设定改变]

## 创作任务
请创作[具体章节/片段]，场景是[场景描述]。

## 创作背景
- 剧情起点：[故事从哪里开始]
- 角色状态：[当前角色的心理/处境]
- 冲突点：[主要矛盾是什么]

## 创作要求

### 内容要求
- 情节：[具体情节走向]
- 重点：[需要重点描写的部分]
- 人物：[哪些角色出场，如何互动]

### 风格要求
- 叙述视角：[第一人称/第三人称限制/第三人称全知]
- 文笔：[简洁/华丽/幽默/沉重/治愈]
- 贴近原作度：[高度贴近/可适度创新]

### 格式要求
- 字数：[数字]字左右
- 结构：[分几段/章节结构]
- 输出形式：[正文/对话/混合]

## 同人专属要求
- 避免OOC：[列出角色的核心性格特征]
- 圈层梗：[可适当使用的梗，或不使用]
- CP设定：[如果有CP，说明攻受/主次关系]
- 雷点规避：[读者普遍不喜欢的元素]

## 禁忌
- 不要[禁忌1]
- 不要[禁忌2]
```

**示例**：
```
# 角色设定
你现在是一名资深同人小说创作专家，深度研究过《原神》，
擅长人物性格还原和原作风格模仿，深谙同人圈文化和读者喜好。

## 原作信息
- 原作名称：《原神》
- 世界观设定：提瓦特大陆，七神统治的幻想世界
- 关键人物：
  * 钟离（岩王帝君）：沉稳可靠，温文尔雅，带有千年古人的从容
  * 公子（达达利亚）：热情开朗，战斗狂，至冬国第十一执行官
- 人物关系：看似上下级，实则相互理解的知己
- 时间线：主线剧情之后，公子常驻璃月
- AU设定：无，贴近原作

## 创作任务
请创作一个钟离×公子的温馨短篇，场景是公子准备回至冬国前的最后一次见面。

## 创作背景
- 剧情起点：公子在璃月港向钟离道别
- 角色状态：公子即将离开，内心复杂；钟离平静中带着一丝不舍
- 冲突点：情感含蓄，没有直接冲突，是内心的不舍

## 创作要求

### 内容要求
- 情节：两人在港口边聊天，回顾相处时光
- 重点：人物的细腻情感，含蓄的表达方式
- 人物：钟离和公子的互动，体现两人的理解和默契

### 风格要求
- 叙述视角：公子第一人称视角
- 文笔：温馨治愈，含蓄细腻
- 贴近原作度：高度贴近，保持角色原有说话方式

### 格式要求
- 字数：1000-1500字
- 结构：开篇相遇→回忆片段→道别→内心独白
- 输出形式：以对话为主，辅以心理描写

## 同人专属要求
- 避免OOC：
  * 钟离：保持沉稳、从容，说话带古风韵味
  * 公子：保持热情、真诚，但离别时要有落寞感
- 圈层梗：可适当使用"岩王帝君退休"、"公子归国"等梗
- CP设定：钟离攻，公子受，关系平等
- 雷点规避：不要过度甜腻，保持角色的矜持感

## 禁忌
- 不要让钟离突然变得话多
- 不要使用过于现代的梗
- 不要偏离原作世界观
```

### 模板2：同人小说CP文
适用于有明确配对的同人创作。

```
# 角色设定
你现在是一名同人圈资深写手，深耕[原作名称]同人圈[X]年，
擅长写[CP关系]文，深谙粉丝喜好和圈层梗。

## CP信息
- CP名称：[如"钟离×公子"]
- 攻受设定：[谁攻谁受，关系动态]
- 关系基础：[原作中的关系基础]
- 读者偏好：[这对CP的粉丝喜欢什么风格]

## 原作信息
- 原作名称：[原作名称]
- 关键人物：[CP角色的核心特征]
- 世界观：[相关世界观设定]

## 创作任务
请创作一个[CP]同人，[场景/情节描述]。

## 标签设定
- 情感类型：[甜文/虐文/酸甜/温馨/治愈]
- 剧情类型：[日常/剧情/冒险/治愈]
- 结局类型：[HE/BE/开放式]

## 创作要求

### 情感要求
- 情感基调：[轻松/沉重/温馨/虐心]
- 甜度：[10分制]
- 虐点：[列出虐点位置]
- 情感发展：[从疏远到亲密/从暗恋到表白等]

### 内容要求
- 情节：[具体情节]
- 重点：[互动方式、情感表达]
- 经典梗：[可使用的CP经典梗]

### 风格要求
- 叙述视角：[视角选择]
- 文笔：[风格描述]
- 人物还原度：[高度还原/可适度创新]

## CP专属禁忌
- 不要[CP相关禁忌，如OOC、OOC严重、雷点情节]
- 避免[不喜欢的元素]
```

**示例**：
```
# 角色设定
你现在是一名同人圈资深写手，深耕《原神》同人圈2年，
擅长写钟离×公子文，深谙粉丝喜好和圈层梗。

## CP信息
- CP名称：钟离×公子
- 攻受设定：钟离攻，公子受，关系平等，相互尊重
- 关系基础：原作中看似上下级，实则在某种程度上是知己
- 读者偏好：喜欢含蓄细腻、情感真挚、不OOC的文

## 原作信息
- 原作名称：《原神》
- 关键人物：
  * 钟离：沉稳、从容、古风、千年古人的智慧
  * 公子：热情、真诚、战斗狂、内心柔软
- 世界观：提瓦特大陆，璃月是岩神钟离的国家

## 创作任务
请创作一个钟离×公子的温馨日常同人，场景是两人在三碗不过港一起喝酒。

## 标签设定
- 情感类型：温馨治愈，含蓄真挚
- 剧情类型：日常，无大剧情，情感细腻
- 结局类型：开放式，留有余韵

## 创作要求

### 情感要求
- 情感基调：温馨、治愈、含蓄
- 甜度：6分（适中）
- 虐点：无虐
- 情感发展：从日常聊天到情感流露，点到为止

### 内容要求
- 情节：两人在酒馆喝酒，聊起公子的过往经历，钟离给出建议
- 重点：人物对话，细腻的情感互动，钟离的智慧和公子的真诚
- 经典梗："岩王帝君退休"、"公子归国前的最后一次畅饮"

### 风格要求
- 叙述视角：公子第一人称视角
- 文笔：含蓄细腻，情感点到为止
- 人物还原度：高度还原，保持角色原有说话方式

## CP专属禁忌
- 不要让钟离突然变得话多，保持他的从容
- 不要过度甜腻，保持两人的矜持感
- 不要让公子OOC成只会撒娇的人设
- 避免使用过于现代的网络梗
```

## 原创小说模板

### 模板3：玄幻小说开篇
适用于玄幻、仙侠等网文开篇创作。

```
# 角色设定
你现在是一名网文金牌编辑，有[数字]年玄幻小说编辑经验，
熟悉起点平台规则和读者喜好，擅长构建宏大世界观和爽文结构。

## 世界观设定
- 世界名称：[如"九霄大陆"]
- 地理格局：[地图分布、重要地点]
- 力量体系：[等级划分、修炼方法]
- 势力格局：[正邪势力、国家分布]
- 特色设定：[独特的世界观元素]

## 主角设定
- 姓名：[主角姓名]
- 年龄：[年龄]
- 身份：[出身、社会地位]
- 性格：[性格特征、优缺点]
- 动机：[核心动机、想要什么]
- 金手指：[系统/宝物/天赋]

## 创作任务
请创作[书名]的第一章，字数[数字]字。

## 创作要求

### 情节要求
- 开篇冲突：[第一章必须有的冲突]
- 金手指觉醒：[何时、如何觉醒]
- 悬念设置：[结尾悬念]
- 节奏：[快节奏/慢热]

### 结构要求
- 开篇：[前100字吸引读者]
- 发展：[铺垫背景，引入冲突]
- 高潮：[金手指觉醒/打脸情节]
- 结尾：[悬念，吸引看下一章]

### 风格要求
- 叙述视角：[视角选择]
- 文笔：[热血/简洁/华丽]
- 语言：[古风/现代/符合世界观]
- 节奏：[快节奏，冲突密集]

### 平台要求
- 平台：[起点/纵横/晋江等]
- 读者偏好：[爽文/慢热/剧情向]
- 规则：[平台特殊规则]

## 目标读者
- 年龄层：[如"18-35岁男性"]
- 核心看点：[如"升级打脸、废柴逆袭、爽感"]
- 阅读习惯：[如"喜欢快节奏，期待打脸"]
```

**示例**：
```
# 角色设定
你现在是一名网文金牌编辑，有10年玄幻小说编辑经验，
熟悉起点平台规则和读者喜好，擅长构建宏大世界观和爽文结构。

## 世界观设定
- 世界名称：九霄大陆
- 地理格局：中央为天启皇朝，四方为四大家族
- 力量体系：练气→筑基→金丹→元婴→化神
- 势力格局：正道七宗、魔教六殿、散修联盟
- 特色设定：灵气复苏前夕，天才辈出，古籍重现

## 主角设定
- 姓名：林风
- 年龄：16岁
- 身份：被家族放逐的废柴，父亲神秘失踪
- 性格：坚毅、冷静、不择手段但有底线
- 动机：变强寻找父亲，证明自己，守护重要的人
- 金手指：神秘石佩，能吸收他人灵力和战斗经验

## 创作任务
请创作《九霄至尊》的第一章，字数3000字。

## 创作要求

### 情节要求
- 开篇冲突：主角被族中子弟羞辱，觉醒金手指
- 金手指觉醒：石佩发热，吸收对方灵力
- 悬念设置：父亲失踪的线索出现
- 节奏：快节奏，冲突密集

### 结构要求
- 开篇：主角在家族测试中失败，被众人嘲讽
- 发展：回到家中，发现父亲留下的神秘石佩
- 高潮：族中子弟上门羞辱，主角反击，石佩觉醒
- 结尾：发现石佩的秘密，父亲失踪的线索

### 风格要求
- 叙述视角：第三人称限制视角（林风视角）
- 文笔：热血简洁，注重动作和对话
- 语言：符合玄幻设定，不过度古风
- 节奏：快节奏，每段推进情节

### 平台要求
- 平台：起点中文网
- 读者偏好：爽文、快节奏、打脸、升级
- 规则：前三章要有第一个爽点

## 目标读者
- 年龄层：18-35岁男性
- 核心看点：废柴逆袭、打脸爽感、系统/宝物、升级
- 阅读习惯：喜欢快节奏，期待打脸和升级
```

### 模板7：快速同人创作
适用于简单同人创作场景。

```
你是一名同人小说创作专家，擅长[原作名称]同人创作。
```

## 模板使用建议

1. **选择合适的模板**：根据创作场景选择对应的模板
2. **填充必要信息**：根据模板结构填写具体信息
3. **调整细节**：根据实际需求调整部分内容
4. **组合使用**：可以将多个模板的元素组合使用
5. **简化版本**：对于简单场景，使用简化版模板

## 模板扩展方向

1. **添加平台特色**：不同平台有不同的风格和规则
2. **添加类型特色**：细化不同类型的特定要求
3. **添加风格选项**：提供更多风格选择
4. **添加结构变体**：不同的情节结构选项
5. **添加角色变体**：不同的角色设定选项
