## 概览
本文档总结提示词设计中的常见问题和陷阱，帮助识别并避免这些错误。

## 问题识别

### 如何检测问题提示词

**信号1：输出不符合预期**
- 大模型无法准确理解需求
- 输出内容偏离目标
- 需要多轮修正才能得到正确结果

**信号2：回答不够深入**
- 输出过于浅显
- 缺少细节和专业性
- 无法满足实际使用需求

**信号3：理解偏差严重**
- 大模型误解了核心意图
- 关注了错误的方向
- 需要反复澄清和纠正

**信号4：格式混乱**
- 输出结构不清晰
- 格式不符合要求
- 难以阅读和使用

## 常见陷阱

### 陷阱1：目标过于宽泛

**问题描述**：
提示词的目标描述过于宽泛，缺乏具体指向。

**错误示例**：
- "帮我写个方案"
- "分析一下这个"
- "给我一些想法"

**问题原因**：
- 没有明确具体任务类型
- 缺少目标范围和边界
- 不清楚要达成什么效果

**避免方法**：
```
✅ 正确做法：
明确说明：
- 任务类型：方案设计/分析评估/创意生成
- 目标范围：哪个领域/针对什么对象
- 期望效果：解决什么问题/达到什么标准

示例：
"为我设计一份社交媒体营销方案，针对新产品X，目标是在3个月内
获得10000个精准用户，预算5万元"
```

---

### 陷阱2：上下文缺失

**问题描述**：
缺少必要的背景信息，大模型无法理解上下文。

**错误示例**：
```
❌ 错误："请优化这段文案"

问题：
- 这段文案是什么？
- 目标受众是谁？
- 使用场景是什么？
- 要达成什么目标？
```

**问题原因**：
- 假设大模型已知所有背景
- 没有提供足够的环境信息
- 缺少场景和目标说明

**避免方法**：
```
✅ 正确做法：
提供完整上下文：
- 背景：这是一个什么项目的文案
- 目标：要提高转化率/知名度/用户互动
- 受众：年轻人/专业人士/企业客户
- 场景：用于官网/广告/社交媒体
- 现状：当前文案存在什么问题

示例：
"请优化以下产品介绍文案。这是一个面向大学生的
在线学习平台，目标是提高课程报名转化率。
当前文案过于技术化，不够吸引年轻人。
文案内容：[附原文]"
```

---

### 陷阱3：约束条件不足

**问题描述**：
没有明确输出格式、长度、风格等约束条件。

**错误示例**：
```
❌ 错误："总结这篇文章"

问题：
- 要多长的总结？
- 用什么格式？
- 总结到什么程度？
- 要关注哪些要点？
```

**问题原因**：
- 认为约束不重要
- 没有考虑输出使用场景
- 缺少对输出质量的预期

**避免方法**：
```
✅ 正确做法：
明确约束条件：
- 长度：200字/500字/1000字
- 格式：段落/列表/表格/结构化报告
- 深度：概述/详细分析/专家级
- 要点：必须包含的关键内容
- 风格：正式/非正式/专业/通俗

示例：
"请将这篇文章总结为3个要点，每个要点不超过50字，
使用列表形式输出，保持客观语气"
```

---

### 陷阱4：使用歧义表达

**问题描述**：
使用模糊、多义的词汇，容易产生误解。

**错误示例**：
```
❌ 错误：
- "给我一些好的建议"
- "分析一下这个数据"
- "帮我优化一下"

问题："好"的标准是什么？"一下"的程度？
```

**问题原因**：
- 使用主观性词汇
- 缺少量化标准
- 存在多种理解方式

**避免方法**：
```
✅ 正确做法：
使用精确表达：
- 替换"好的建议"为"符合以下标准的建议：[具体标准]"
- 替换"分析一下"为"从[维度1、维度2、维度3]分析"
- 替换"优化一下"为"优化以达到[具体目标]"

示例：
"请提供3个创新营销建议，要求：1.预算可控在2万以内
2.执行周期不超过1个月 3.预期ROI达到300%以上"
```

---

### 陷阱5：结构混乱

**问题描述**：
提示词层次不清，信息堆砌，逻辑混乱。

**错误示例**：
```
❌ 错误：
"帮我写个文案要吸引人还要有创意但是不要太长
大概300字左右吧主要是推广我们的新产品
新产品是关于人工智能的面向企业用户的..."

问题：
- 信息没有组织
- 逻辑顺序混乱
- 难以抓住重点
```

**问题原因**：
- 没有使用结构化表达
- 信息组织随意
- 缺少层次划分

**避免方法**：
```
✅ 正确做法：
使用结构化表达：
- 分段落描述不同内容
- 使用编号或列表
- 按逻辑顺序排列信息

示例：
"请为我撰写一款AI产品推广文案，具体要求如下：

## 目标
- 推广对象：面向企业的AI数据分析平台
- 使用场景：LinkedIn专业推广帖子

## 内容要求
1. 开头：用数据痛点吸引注意力
2. 中间：介绍产品核心价值和差异化
3. 结尾：引导用户了解详情

## 约束条件
- 字数：300-400字
- 风格：专业但不失亲和力
- 包含：#AI #数据分析 #企业服务标签"
```

---

### 陷阱6：一次性提出过多要求

**问题描述**：
在一个提示词中包含过多、过复杂的任务。

**错误示例**：
```
❌ 错误：
"请帮我分析这个市场报告，还要找出机会点，
生成营销策略，制定执行计划，
预测销售业绩，并评估风险..."

问题：
- 任务过于复杂
- 容易遗漏细节
- 输出质量下降
```

**问题原因**：
- 想要一次性完成所有工作
- 没有合理拆分任务
- 超出单次处理的合理范围

**避免方法**：
```
✅ 正确做法：
拆解复杂任务：
- 将大任务分解为多个子任务
- 按逻辑顺序逐步完成
- 每次专注于一个明确目标

示例：
"分步完成市场分析：

步骤1：首先分析市场报告，提取关键数据
步骤2：基于分析结果，识别市场机会
步骤3：根据机会点，制定营销策略
步骤4：为策略制定执行计划

请先完成步骤1"
```

## 错误案例对比

### 案例1：文案优化

**错误版本**：
```
"帮我优化这个产品描述，让它更好"
```

**问题**：
- 没有说明产品的特点和目标
- "更好"的标准不明确
- 缺少上下文信息

**正确版本**：
```
"请优化以下产品描述。这是一款面向年轻女性的
护肤品牌，目标是在小红书平台提高转化率。

当前问题：描述过于技术化，不够吸引人
优化目标：突出产品卖点，语言更亲切自然
约束条件：300字以内，包含2-3个emoji

原文：[附原文]"
```

---

### 案例2：数据分析

**错误版本**：
```
"分析一下这个Excel文件"
```

**问题**：
- 不知道要分析什么内容
- 缺少分析维度和目标
- 没有输出格式要求

**正确版本**：
```
"请分析附件销售数据Excel文件，重点关注：

分析维度：
1. 月度销售趋势变化
2. 产品类别销售占比
3. 异常数据波动点识别

输出要求：
- 使用表格展示关键数据
- 图表可视化趋势（可描述图表类型）
- 总结3个关键发现
- 字数控制在500字左右"
```

---

### 案例3：任务规划

**错误版本**：
```
"帮我规划一个项目"
```

**问题**：
- 完全没有项目信息
- 不知道项目的类型和规模
- 缺少资源和时间约束

**正确版本**：
```
"请为以下项目制定执行计划：

项目背景：
公司计划开发一款移动端健身APP
目标用户：20-35岁健身爱好者
预算：50万元
周期：6个月

请提供：
1. 项目阶段划分和时间节点
2. 关键里程碑和交付物
3. 团队配置建议（角色和人数）
4. 风险点和应对措施

输出格式：使用Markdown表格展示"
```

---

### 案例4：内容创作

**错误版本**：
```
"写个关于人工智能的文章"
```

**问题**：
- 主题过于宽泛
- 没有明确角度和深度
- 缺少受众和场景信息

**正确版本**：
```
"请撰写一篇关于人工智能的文章，具体要求：

主题方向：AI在医疗领域的应用
目标受众：医疗行业从业者
文章长度：1500-2000字
内容结构：
1. 引言：AI医疗的现状和意义
2. 主体：具体应用场景（影像诊断、药物研发等）
3. 挑战：技术瓶颈和伦理问题
4. 展望：未来发展趋势

风格要求：专业、客观、数据支撑
参考材料：[附参考资料链接]"
```

## 自检清单

在使用提示词前，对照以下清单进行检查：

### 完整性检查
- [ ] 是否明确说明了任务目标？
- [ ] 是否提供了必要的背景信息？
- [ ] 是否说明了使用场景和目标受众？

### 清晰性检查
- [ ] 目标是否具体明确？
- [ ] 是否使用了模糊或歧义的词汇？
- [ ] 是否避免了"一些"、"一下"等不确切表达？

### 约束检查
- [ ] 是否明确了输出格式？
- [ ] 是否设定了长度限制？
- [ ] 是否说明了语言风格？
- [ ] 是否列出了必须包含/避免的内容？

### 结构检查
- [ ] 信息组织是否清晰？
- [ ] 是否使用了层次结构？
- [ ] 逻辑顺序是否合理？

### 可操作性检查
- [ ] 大模型能否直接执行？
- [ ] 是否需要额外的澄清？
- [ ] 任务范围是否合理？

## 改进建议

1. **自问自答法**：在发送提示词前，试着回答"如果我是AI，我能理解这个要求吗？"

2. **迭代优化法**：先写一个基础版本，然后逐项对照检查清单完善

3. **参考模板法**：使用参考模板作为起点，根据具体需求调整

4. **用户测试法**：让目标用户试用提示词，收集反馈并改进

5. **版本记录法**：保留不同版本的提示词，记录改进过程

## 持续改进

提示词优化是一个持续的过程：
- 根据输出质量调整提示词
- 总结成功和失败的案例
- 建立自己的提示词库
- 关注提示词工程的最佳实践
