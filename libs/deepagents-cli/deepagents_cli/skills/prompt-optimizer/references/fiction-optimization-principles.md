## 概览
本文档提供小说创作提示词优化的核心原则，特别针对同人小说和不同类型小说的创作需求。

## 核心原则

### 原则1：角色设定优先
小说创作不同于普通文本生成，需要专业的创作视角。

**为什么重要**：
- 大模型需要明确自己的创作身份
- 不同的创作角色有不同的表达习惯和关注点
- 专业角色能更好地理解创作要求和风格

**实施方法**：
```
设定结构：
- 角色名称：[专业身份]
- 专业背景：[经验、专长、理解]
- 创作风格：[擅长领域、写作特点]

示例：
你是一名同人小说创作专家，有8年创作经验，
擅长原作人物还原和风格模仿，深谙同人圈文化。
```

### 原则2：原作信息完整性
同人小说必须基于原作，信息缺失会导致严重OOC。

**必须包含的原作信息**：
- **原作名称**：明确的出处
- **世界观设定**：背景、规则、势力
- **人物设定**：性格、能力、关系、口癖
- **时间线**：剧情发生在什么阶段
- **AU设定**：如果是平行世界，说明哪些设定改变

**示例**：
```
❌ 缺失："写个火影同人"
✅ 完整："原作：《火影忍者》，时间线：佩恩战后，
主角：鸣人，性格设定：热血中带着成长的沉稳，
背景：木叶村正在重建"
```

### 原则3：风格约束明确性
小说风格对阅读体验影响巨大。

**风格约束维度**：
- **叙述视角**：第一人称/第三人称限制/第三人称全知
- **文笔风格**：华丽/简洁/幽默/沉重/治愈
- **语言特色**：古风/现代/二次元/严肃文学
- **节奏把控**：快节奏爽文/慢节奏细腻/张弛有度

**示例**：
```
风格要求：
- 视角：第三人称限制视角（以主角视角）
- 文笔：简洁有力，注重动作和对话
- 语言：符合时代背景，避免现代梗
- 节奏：快节奏，每段对话后推进情节
```

### 原则4：受众意识
知道写给谁看，才能写出合适的内容。

**受众要素**：
- **年龄层**：青少年/成年/全年龄
- **性别偏好**：男性/女性/不分
- **阅读习惯**：网文读者/文学读者/同人圈读者
- **平台规则**：起点/晋江/LOFTER/AO3等

**示例**：
```
目标读者：18-30岁女性，晋江言情读者
阅读偏好：甜文、HE（大团圆结局）、细腻情感
平台规则：晋江禁止露骨描写，情感要含蓄
```

### 原则5：情节结构化
小说需要清晰的情节走向。

**情节结构要素**：
- **开篇**：吸引读者，引入冲突
- **发展**：矛盾升级，人物成长
- **高潮**：最激烈的冲突或转折
- **结局**：解决矛盾，回应主题

**优化方法**：
```
情节要求：
- 开篇：主角在危机中觉醒金手指
- 发展：小试牛刀，打脸小反派
- 高潮：面对强大敌手的终极对决
- 结局：获得关键资源，为下一卷铺垫
```

## 同人小说专项原则

### 原则6：尊重原作设定
同人的核心是"基于原作"，不是"脱离原作"。

**尊重方式**：
- **人物性格**：保持原作人物的核心性格特征
- **世界观规则**：不随意推翻原作设定
- **经典台词**：适当保留角色的标志性语言
- **关系基础**：尊重原作中的人物关系

**避免OOC的方法**：
```
❌ 错误示例：
让原本高冷的斯内普突然变得话多温柔

✅ 正确做法：
保持斯内普的严厉和讽刺，在特定场景下流露一丝关心
"斯内普轻蔑地哼了一声，'波特，你以为你是救世主
就能无视规则吗？'但他的目光在哈利身上停留了片刻。"
```

### 原则7：同人文化理解
同人圈有独特的文化和表达方式。

**同人元素**：
- **圈层梗**：圈内的经典梗和笑点
- **标签文化**：甜文、虐文、BE、HE等标签
- **CP设定**：配对关系、攻受设定（BL同人）
- **雷点规避**：读者普遍不喜欢的元素

**示例**：
```
同人要求：
- 标签：甜文、HE、温馨日常
- CP：钟离×公子（攻受关系明确）
- 雷点规避：不要涉及NTR、不要OOC严重
- 圈层梗：可适当使用"岩王帝君退休"等梗
```

### 原则8：AU设定清晰化
如果是平行世界（AU），必须清晰说明设定变化。

**AU类型**：
- **校园AU**：魔法世界→现代学校
- **职场AU**：武侠世界→现代公司
- **奇幻AU**：现代→异世界
- **设定微调**：保留原作，调整部分设定

**说明方法**：
```
AU设定：现代职场AU
- 原作：哈利·波特魔法世界
- 现化：现代伦敦，霍格沃茨是跨国公司
- 人物对应：
  * 哈利：新人销售
  * 斯内普：严厉的部门经理
  * 邓布利多：CEO
- 保留元素：学院竞争（部门竞争）、四大学院（四大部门）
```

## 原创小说专项原则

### 原则9：世界观完整性
原创小说需要从零构建世界，信息必须完整。

**世界观要素**：
- **地理背景**：世界地图、国家分布、重要地点
- **力量体系**：等级划分、修炼方法、特殊能力
- **势力格局**：正邪对立、门派林立、国家关系
- **文化背景**：科技水平、社会制度、宗教信仰

**优化示例**：
```
世界观设定：
- 地理：九州大陆，中央为天启皇朝
- 力量：练气→筑基→金丹→元婴→化神
- 势力：正道七宗、魔教六殿、散修联盟
- 特点：灵气复苏前夕，天才辈出
```

### 原则10：主角设定立体化
主角是小说的核心，必须设定清晰。

**主角要素**：
- **基本信息**：姓名、年龄、外貌
- **性格特征**：优点、缺点、成长方向
- **身份背景**：出身、经历、社会地位
- **核心动机**：想要什么、为什么想要
- **金手指**：系统、宝物、天赋等

**设定示例**：
```
主角设定：
- 姓名：林风
- 年龄：16岁
- 性格：坚毅、冷静、不择手段但有底线
- 背景：被家族放逐的废柴，父亲神秘失踪
- 动机：变强寻找父亲，证明自己
- 金手指：神秘石佩，能吸收他人灵力
```

### 原则11：类型特征明确
不同类型小说有特定的创作规律。

**常见类型**：
- **玄幻仙侠**：升级打脸、宏大世界观、爽文节奏
- **都市言情**：情感细腻、现代背景、都市生活
- **科幻未来**：科技设定、未来社会、硬核科幻
- **无限流**：穿越不同世界、生存游戏、任务导向

**类型优化要点**：
```
玄幻小说特征：
- 核心看点：升级、打脸、爽感
- 节奏：快节奏，冲突密集
- 结构：小冲突→大冲突→终极冲突
- 语言：热血、直白、不拖沓

言情小说特征：
- 核心看点：情感互动、人物成长
- 节奏：张弛有度，情感细腻
- 结构：相遇→相知→冲突→和解
- 语言：优美、含蓄、心理描写丰富
```

## 类型小说优化要点

### 玄幻小说
- **力量体系清晰**：等级、修炼方法、突破条件
- **打脸爽感强烈**：主角被质疑→展现实力→众人震惊
- **世界设定宏大**：地图不断扩展，势力不断升级
- **金手指合理化**：系统/宝物的来源和限制

### 言情小说
- **人物关系清晰**：主角之间的情感发展曲线
- **甜虐节奏把控**：糖点和虐点的分布
- **配角功能明确**：助攻、阻碍、调剂气氛
- **HE/BE设定**：结局类型要提前明确

### 同人小说
- **原作理解深入**：避免严重OOC
- **同人梗运用得当**：圈内梗能引起共鸣
- **CP关系明确**：配对关系和互动模式
- **受众偏好尊重**：了解读者的雷点和萌点

### 无限流小说
- **世界设定多样**：不同副本的规则和特色
- **生存压力强烈**：死亡威胁、任务紧迫
- **主角能力成长**：在每个世界获得新能力
- **团队关系动态**：团队成员的互动和变化

## 实践建议

1. **角色设定要具体**：不要用"你是个好作者"，要说"你是同人小说创作专家"
2. **原作信息要完整**：同人小说必须提供足够的原作背景
3. **风格约束要明确**：叙述视角、文笔风格、语言特色都要说清楚
4. **目标读者要明确**：知道写给谁看，才能写出合适的内容
5. **避免过度限制**：给大模型一定的创作自由，不要规定每个细节
