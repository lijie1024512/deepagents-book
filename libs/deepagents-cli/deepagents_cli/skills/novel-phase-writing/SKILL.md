# 阶段5：正文写作

## 目标
将大纲转化为高质量正文。让读者**感受**，而不是**告诉**读者。

## 前置读取
- 读取 `engine.md` → 引擎状态和核心矛盾
- 读取大纲 → 章节情节点和核心画面
- 续写时：读最近2-3章正文 + `progress.md` + `style_notes.md`

## 流程

### 1. 前3章精磨（多版本）
第1章生成3个版本（不同开场/节奏/首句），第2-3章至少2个版本。用户选最好的，反馈后改进。

### 2. 逐场景生成
每章流程：解析大纲→场景规划（展示确认）→逐场景生成→质量检查

场景字数自适应：低谷500-800字 / 转折300-500字 / 高峰800-1500字 / 释放400-600字

### 3. 核心写作原则
- **展现而非告诉**：❌"他很紧张" → ✅"握刀的手微微发抖"
- **避免流水账**：禁止连续3句纯叙述
- **角色声音**：每个角色对话有独特风格

### 4. 滚动生成（第4章起）
5章一批，每批后：引擎健康检查 + 收集反馈记入 `progress.md`

## 质量标准

以下是一个合格场景的示例。参考**质量水平**，不要照搬。

### 示例（水浒世界观，武大郎引擎，第1章开场）

> 灶台上的药罐咕嘟冒着白气，满屋子都是苦涩的药味。
>
> 潘金莲端着碗从帘子后面走出来，脸上挂着恰到好处的担忧。那碗汤微微冒着热气，她走得很稳，像是怕洒了一样小心。
>
> "大郎，趁热喝了吧。"
>
> 你看着那碗汤。
>
> 上辈子你看过水浒传。你知道这碗汤里有什么。你知道她昨天去了王婆茶铺。你知道西门庆上午刚从县衙回来。
>
> 她把碗放在桌上，汤面泛着一层油光。
>
> 你的手在被子下面攥紧了。

**为什么这个场景有效**：
- 没有旁白解释"主角很紧张"——通过"攥紧被子"展现
- 没有内心独白罗列前因后果——通过三个"你知道"暗示先知信息
- 潘金莲的描写基于可观察行为（端碗、走路、表情），不是"她心想要毒死你"
- 紧张感来自读者知道真相但角色不能反应的信息差

## 正文格式要求

正文内容面向中文Word文档排版，必须遵循以下规范：
- 禁止使用任何Markdown格式符号（`**粗体**`、`*斜体*`、`# 标题`、`- 列表`等）
- 正文只使用纯文本，段落之间用空行分隔
- 对话使用中文引号（""）包裹
- 不要在content中包含章节标题（complete_chapter会自动生成）

## 完成标志
- 用 `complete_chapter(chapter, content, summary, title)` 保存
- 用户确认正文质量
