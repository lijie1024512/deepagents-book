# 仿写生成指南

## 核心：源文原文就是风格参考

生成每一章时，`get_generation_context(chapter=N)` 会自动提供源小说第N章的原文。

**你的写作流程**：
1. 仔细阅读源小说该章原文，感受其句式节奏、描写密度、对话风格
2. 在脑中把原著场景"映射"到改编方案的设定里
3. 模仿原文风格写出改编后的内容
4. 保存：`save_chapter(chapter=N, content="...", summary="...", title="...")`

## 写作约束

### 文风模仿（最重要）
- **句式长度**：和源文保持一致。源文用短句就用短句，源文用长句就用长句
- **描写密度**：源文每段写多少环境描写，你也写多少
- **对话风格**：源文的对话口语化程度、插科打诨的频率要保持
- **内心独白**：格式和频率和源文一致
- **转场方式**：源文用星号分隔就用星号，用时间跳跃就用时间跳跃

### 结构对应
- 章节长度和源文对应章节相近
- 爽点位置和源文对应（如果源文第3章结尾有个小高潮，你的第3章结尾也要有）
- 日常/紧张的比例和源文一致

### 改编忠实性
- 按 `adaptation_plan` 中该章的计划执行
- 使用 `character_mapping` 中的新角色名称和设定
- 遵循 `power_system` 中的新金手指规则

### 前后连贯
- 参考上下文中的"前文摘要"，保持人物状态一致
- 不要出现前后矛盾（角色名字、能力状态、关系变化）

## 批次生成

- 每生成5-10章暂停一次，让用户审阅
- 暂停时汇报：已完成章节列表 + 下一批计划
- 用户可在批次间调整方向

## 质量自查

每章生成后自查：
- 文风是否像源小说？（对比一下句式长度和描写密度）
- 改编是否按计划执行？
- 前后有没有矛盾？
- 角色行为是否符合新设定？

## 禁止事项

- 不要生成"文风总结"代替实际写作——直接写正文
- 不要跳章生成
- 不要遗漏改编计划中的关键改动
- 不要让金手指的行为违反 `power_system` 中的设定
