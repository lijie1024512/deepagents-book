# 网文写作技法词表

> 精读源文时的分析锚点。识别源文用了哪些技法，改编时复用同类技法、写出更好的版本。

---

## 一、开场技法

| 技法 | 识别特征 | 示例 |
|------|---------|------|
| **先声夺人** | 第一句就是动作/对话/冲突，不铺垫直接进场 | "砰的一声，门被踹开——" |
| **悬念前置** | 开头抛出一个反常现象或疑问，读者带着问题往下读 | "他醒来时，发现自己躺在一个完全陌生的房间里，而床头放着自己的遗照" |
| **场景即入** | 开头就是环境描写，通过场景交代氛围和世界观 | "灰蒙蒙的天空下，铁锈色的管道像巨蟒一样缠绕在建筑外墙上" |
| **倒叙切入** | 先写结果/高潮片段，再回到起因 | "三天后他会明白，这个决定改变了一切。但此刻，他只是随手接过了那张纸条" |
| **内心独白开场** | 以主角的思考/感受开头，快速建立代入感 | "又是这个梦。每次醒来都记不清细节，只剩下指尖残留的冰凉触感" |

## 二、节奏技法

| 技法 | 识别特征 | 效果 |
|------|---------|------|
| **欲扬先抑** | 先写主角处于劣势/被轻视，然后反转展示实力 | 压抑积累的释放感，爽感加倍 |
| **快进慢写** | 日常一笔带过（快进），关键场景逐帧展开（慢写） | 重点场景的沉浸感，避免流水账 |
| **断崖悬停** | 在最紧张的时刻切到另一条线或直接结束 | 制造"想看下一章"的冲动 |
| **节奏变速** | 连续短句密集段（紧张）突然切换到一个长句（喘息） | 文字层面的呼吸感，防止阅读疲劳 |
| **压抑-释放循环** | 连续几段压力积累，然后一个爽点集中释放 | 网文最核心的节奏模型 |
| **三段递进** | 同类事件出现三次，一次比一次强，第三次质变 | 积累→积累→爆发的满足感 |

## 三、爽点技法

| 技法 | 识别特征 | 典型场景 |
|------|---------|---------|
| **信息差碾压** | 读者/主角知道真相，对手不知道，看对手自以为是地作死 | 装弱被欺→亮实力碾压 |
| **扮猪吃虎** | 主角隐藏实力，在关键时刻才暴露 | "你确定要和我比？""确定。"（对手不知道主角真实等级） |
| **步步升级** | 连续闯关，每一关比上一关难，每次过关都更爽 | 淘汰赛/试炼塔/连续挑战 |
| **打脸反转** | 有人当众看不起主角，然后被事实打脸 | "这种垃圾也能..."（话没说完，被结果震惊） |
| **底牌揭示** | 主角/敌人突然亮出隐藏的能力或身份 | 战斗到绝境→新能力觉醒/真实身份暴露 |
| **鉴宝慧眼** | 主角凭金手指发现别人看不出的价值 | 废品堆里淘到宝/别人扔掉的东西主角知道真实价值 |
| **以弱胜强** | 实力差距明显但靠策略/金手指特性赢 | 不是硬碰硬，而是利用规则/环境/对手弱点 |

## 四、描写技法

| 技法 | 识别特征 | 用法 |
|------|---------|------|
| **五感交织** | 一段描写同时调动2-3个感官通道 | 不只"看到"，还"闻到铁锈味""听到嗡嗡声""皮肤感到潮湿" |
| **以小见大** | 通过一个微小细节暗示宏大背景 | 不写"城市很破败"，写"门把手上的铜绿已经把锁孔堵死了" |
| **白描速写** | 短句、无修饰、动作连续，制造速度感 | "他转身。拔刀。挡。火星四溅。" |
| **工笔细描** | 长句、大量修饰词、逐层展开细节 | 用于重要场景首次亮相，给读者完整画面 |
| **感官联觉** | 用A感官描述B感官的体验 | "那声音像砂纸在眼球上打磨""光线甜得发腻" |
| **环境映射情绪** | 用场景细节暗示角色心理状态 | 角色焦虑时写"风把窗帘吹成一团"，角色平静时写"阳光在地板上慢慢移动" |
| **动态静物** | 用动词写静态事物，让场景有活力 | 不写"墙上有裂缝"，写"裂缝从墙角爬到天花板" |

## 五、人物技法

| 技法 | 识别特征 | 效果 |
|------|---------|------|
| **动作性格化** | 不直接说"他很紧张"，通过特定动作表现 | "他又开始转笔了"（紧张时的习惯） |
| **对话潜台词** | 角色说的话和真实意思不同，读者能读出来 | 表面在聊天气，实际在试探对方立场 |
| **细节暗示** | 通过衣着/物品/小习惯暗示角色背景和性格 | 袖口磨损→经济紧张；随身带刀→警惕性高 |
| **反差设定** | 外表和内心/能力之间有落差 | 看起来文弱→实际最强；看起来冷漠→暗中关心 |
| **台词标签** | 角色有独特的说话方式、口头禅、语气 | 这个角色喜欢反问，那个角色说话永远带"嗯" |
| **镜像对比** | 两个角色面对同一情况做出相反反应 | 凸显性格差异，同时推进两条人物线 |
| **行为弧光** | 同一行为在前期和后期有不同表现，体现成长 | 前期遇到冲突就退缩，后期主动迎上 |

## 六、悬念/伏笔技法

| 技法 | 识别特征 | 用法 |
|------|---------|------|
| **切幕悬停** | 关键时刻突然切换视角或场景 | 打斗最激烈时切到旁观者视角/另一条线 |
| **答案延迟** | 抛出问题后不立刻回答，间隔几段甚至几章后才揭示 | 维持读者好奇心，增加翻页欲 |
| **悬念递进** | 一个悬念刚解开，立刻衍生出更大的悬念 | 防止"解谜后无聊"，保持持续吸引力 |
| **草蛇灰线** | 在不起眼的地方埋入细节，后面成为关键线索 | "他无意间注意到角落的XX"——30章后这个XX成为关键 |
| **误导与反转** | 引导读者形成一个判断，然后用事实推翻 | "一切证据都指向A——但真相是B" |
| **多重真相** | 同一事件有表面解释和深层解释 | 第一次解读是误会，第二次解读才是真相，增加层次 |

## 七、转场技法

| 技法 | 识别特征 |
|------|---------|
| **时间跳切** | "三天后""第二天一早"——直接跳过无关时间 |
| **空间转移** | 通过角色移动自然切换场景 |
| **意识流过渡** | 角色的一个念头引出下一个场景（"说起来，那件事...") |
| **物件关联** | 上一个场景的某个物品/词语，自然引出下一个场景 |
| **对比切换** | 两个场景形成对比（热闹vs安静、成功vs失败），增强戏剧效果 |

---

## 使用方法

分析源文章节时，对照此表识别：
1. 开场用了什么技法？
2. 节奏怎么安排的？（哪里快进、哪里慢写、爽点在哪）
3. 爽点属于哪种类型？
4. 描写用了什么手法？哪些感官通道？
5. 人物怎么刻画的？有没有潜台词/动作性格化？
6. 悬念/伏笔怎么处理的？

用具体的技法名称输出分析结果，而不是笼统的"写了一个场景""描述了环境"。
