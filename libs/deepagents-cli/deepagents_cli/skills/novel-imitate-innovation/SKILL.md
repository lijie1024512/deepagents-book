# 仿写创新方法论

仿写的核心价值不在于复制，而在于**在源文骨架上生长出新的生命**。规划阶段设计了蓝图，但真正的创新发生在每一章的写作中。

## 一、角色偏离：让角色"活过来"

### 原则
改编角色不是源角色的换名版本。每写一章，角色都应该因为**新世界观、新金手指、新关系**而产生源角色不会有的反应。

### 偏离方法

**1. 决策分叉**
在源文中角色做出关键决策的地方，问："如果换成我的角色，以他/她的性格和处境，会做同样的选择吗？"
- 相同决策 → 至少让动机不同（源角色因为A原因，改编角色因为B原因）
- 不同决策 → 这是最好的偏离点，让故事走向不同的分支

**2. 关系重构**
源文的关系模式（师徒、对手、暧昧）可以保留功能，但改变动力：
- 源文师徒关系基于实力崇拜 → 改编可以基于理念认同或利益交换
- 源文对手关系基于嫉妒 → 改编可以基于路线之争

**3. 金手指塑造性格**
金手指的使用体验会塑造角色的行为模式：
- 如果金手指需要承受痛苦 → 角色逐渐培养出高痛苦耐受力，影响日常行为
- 如果金手指依赖社交 → 角色变得更善于观察和操控人际关系
- 如果金手指有副作用 → 角色对使用时机更加谨慎，性格更加审慎

### 演化追踪
每章写完后调用 `evolve_character(character_name, chapter, changes, personality_shift, relationship_changes)` 记录。下一章的 `get_generation_context` 会自动展示演化轨迹。

## 二、金手指演化：世界越深，金手指越活

### 原则
规划阶段用"世界土壤法"设计的金手指，是扎根于世界的种子。它的演化不是"能力变强"，而是**主角对世界挖得越深，金手指与世界的绑定越紧密，生长出新的枝叶**。

核心逻辑：
```
主角探索世界新层面 → 发现新的"世界土壤" → 金手指从新土壤中长出新能力/新限制
```

**实操**：每次需要让金手指演化时，先调用 `get_analysis("world_setting")` 查阅完整世界观，从6个维度（社会结构、能力体系、资源经济、地理空间、势力格局、隐藏设定）中找一个**主角尚未深入接触的层面**作为演化触发点。

每次演化必须回答：**"这个新能力/新限制，是不是只有在这个世界里才会出现？"** 如果答案是"换个世界也行"，说明演化不够世界原生。

### 四种世界驱动的演化模式

**1. 世界探索驱动 —— 挖到新土壤**
主角进入世界的新区域、新阶层、新领域，发现了金手指的新用法：
- 进入新地域 → 当地独有的资源/规则让金手指产生变异
- 接触新阶层 → 该阶层的需求让金手指的某个方面变得重要
- 发现隐藏设定 → 世界的深层规则解锁金手指的隐藏面

> 例：鉴宝类金手指 → 主角进入地下黑市 → 发现"赝品鉴定"能力可以反向用于"制作高级赝品" → 这个新用法只有在这个有地下市场的世界里才有意义

**2. 社会摩擦驱动 —— 关系改变能力**
金手指在社交互动中被迫适应、被改造：
- 与盟友配合 → 金手指发展出"共振/辅助"模式
- 与对手交锋 → 对手的能力体系倒逼金手指发展出防御/克制变体
- 被社会规则限制 → 金手指学会"伪装/收敛"，副产品变成新能力

> 例：经营类金手指 → 主角的商业帝国引起权贵警惕 → 被迫从"做大做强"转向"暗中布局" → 发展出信息网能力 → 这源于这个世界的权贵生态

**3. 规则碰撞驱动 —— 撞到天花板后拐弯**
金手指触碰到世界的硬规则，被迫转向，反而发现新路：
- 世界法则限制了金手指的某个方向 → 被迫往另一个方向发展
- 金手指与世界的另一个体系发生冲突 → 冲突本身产生新的混合能力
- 突破世界某个认知禁区 → 金手指形态发生质变，但代价也质变

> 例：修炼类金手指 → 到了某个境界世界法则压制 → 主角发现不是金手指不够强，而是世界本身有"意志" → 金手指从"修炼工具"演化为"与世界对话的媒介"

**4. 困境倒逼驱动 —— 三大困境推动演化**
规划阶段设计的三个故事困境（身份/选择/升级），在写作中具体展开：

| 困境类型 | 如何推动金手指演化 | 写作要点 |
|---------|-----------------|---------|
| 身份困境 | 金手指的使用暴露/改变主角身份 → 被迫发展"隐匿"或"转型"能力 | 让读者纠结：暴露金手指换取短期利益 vs 隐藏金手指保持长期安全 |
| 选择困境 | 两个同样重要的目标需要金手指往不同方向演化 → 必须选一条路 | 让读者争论：选A路线还是B路线，各有什么后果 |
| 升级困境 | 金手指变强的代价越来越大，升级方式越来越极端 | 让读者期待又担忧：主角为了变强愿意付出什么 |

### 演化节奏建议

```
每3-5章：小演化 — 金手指的新用法、新场景应用（世界探索/社会摩擦驱动）
每10-15章：中演化 — 金手指形态变化、能力维度增加（规则碰撞驱动）
每个大arc：大演化 — 金手指质变，同时引入质变级限制（困境倒逼驱动）
```

每次演化同时记录：
- **新能力/新用法** — 具体是什么
- **世界来源** — 这个演化从世界的哪个层面长出来的
- **新限制** — 演化的代价是什么（必须有）
- **故事推动力** — 这个演化如何自动产生新的情节冲突

### 演化追踪
每次金手指在章节中有展现时，调用 `evolve_golden_finger(chapter, ability_unlocked, limitation_discovered, usage_context, evolution_note)` 记录。其中 `evolution_note` 应注明**世界来源**（从哪个世界层面/社会机制/规则碰撞中演化出来的）。

## 三、情节偏离：同骨架、不同血肉

### 原则
改编世界观和金手指设计提供了创作基础，但具体怎么发生、角色怎么反应、结果怎么收场——这些"血肉"应该是原创的。

### 偏离策略

**1. 事件替换**
源文的核心事件功能（建立世界观/推进关系/展示能力/制造悬念）保持不变，但具体事件可以完全不同：
- 源文"格斗比赛展示能力" → 改编"意外事故中被迫使用能力"
- 功能相同（展示能力），场景完全不同

**2. 因果链重构**
因为金手指、角色都已改变，事件之间的因果关系自然不同：
- 源文：A事件 → 因为源金手指 → B结果
- 改编：A'事件 → 因为新金手指 → C结果（完全不同的后果）

**3. 情绪曲线保持**
源文的情绪节奏（紧张→舒缓→高潮→余韵）值得保持，但产生这些情绪的具体事件应该不同。

### 偏离追踪
对于重要的创意偏离，调用 `log_creative_choice(chapter, category, source_original, adapted_version, reason)` 记录。类别包括：
- `"plot"` — 情节偏离
- `"character"` — 角色偏离
- `"golden_finger"` — 金手指偏离
- `"setting"` — 设定偏离

## 四、创新度自检

每章写完后，用这三个问题检验创新度：

1. **行为测试**：如果把本章的主角换成源文主角，行为模式会一样吗？
   - 如果一样 → 创新不够，角色没有自己的个性
   - 如果不同 → 好，说明角色已经偏离

2. **金手指世界绑定测试**：本章中金手指的使用/演化，和这个世界有关系吗？
   - 换一个世界也能这么用 → 危险信号，金手指脱离了世界土壤
   - 只有在这个世界才有意义 → 好，金手指与世界绑定紧密
   - 补充：连续3章以上金手指用法无变化 → 考虑让主角接触世界的新层面，触发小演化

3. **换名测试**：把本章的对话/描写拿出来，换回源文角色名和设定名，读着像不像源文？
   - 像 → 危险信号，需要增加原创描写和改编元素
   - 不像 → 好，内容是原创的
