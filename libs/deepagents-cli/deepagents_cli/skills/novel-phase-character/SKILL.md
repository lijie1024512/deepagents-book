# 阶段3：角色塑造

## 目标
从选定的引擎推导主角设定。角色的作用是**放大引擎的张力**——让冲突更痛苦、更有看头。

## 前置读取
- `recall("decision")` → 获取引擎方案
- 读取 `engine.md` → 引擎详情

## 流程

### 1. 从引擎推导主角
主角的能力、性格、起点都必须与引擎相关。关键问题：**这个角色+这个引擎，能产生什么"卧槽"画面？**

提供2-3个选项，说明每个选项如何让引擎冲突更痛苦。

### 2. 设计内在矛盾
```
A. 野心 vs 底线 — 想成功但不想变成讨厌的人
B. 孤独 vs 连接 — 习惯独行但渴望同伴
C. 控制 vs 信任 — 想掌控一切但需要依赖
D. 过去 vs 未来 — 放不下的执念影响当下
```

### 3. 设计致命弱点
弱点不是让主角变弱，而是让他变得真实，并且能被故事中的人利用。

### 4. 设计灵魂黑夜
本卷最低谷，必须源于引擎的核心矛盾。低谷越深，逆袭越有力量。

### 5. 设计角色弧光
从A到B的内在成长，这是读者追完一卷后的情感收获。

---

## 质量标准

### 示例（水浒世界观，武大郎引擎）

**主角设定**：穿越成武大郎——矮小、虚弱、社会底层、被全阳谷县看不起。

**为什么这个角色放大引擎张力**：
- 身体虚弱→不能用武力解决，只能用脑子，每一步都惊险
- 社会底层→没有任何资源和人脉，对抗西门庆（有钱有权）的力量差距极大
- "武大郎"这个名字=耻辱标签→每个NPC都带着轻蔑和他说话

**内在矛盾**：穿越者的现代尊严 vs 武大郎的卑微身份。想站起来做人，但每一次出头都增加暴露风险。

**致命弱点**：对"被看不起"有强烈应激反应。西门庆当众羞辱他时，他差点放弃伪装。

**灵魂黑夜**：精心策划的求助信被王婆截获，潘金莲知道他在装傻——伪装被识破，比原剧情更危险。

**角色弧光**：从"活下去就好"到"我不只是要活，我要让武大郎这个名字被人正视"。
